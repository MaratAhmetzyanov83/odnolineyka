# Длины кабельных линий из AutoCAD в таблицу однолинейки (DLN)

Чат 2026-09-26 … 2026-09-28. Объект: ЖК «Остров», папка проекта `C:\Users\marat\Desktop\ЖК остров\01_ПИР_ЭОМ\`.

## Задача

В Excel-таблице однолинейки (лист «Исходные данные») долго и тяжело вручную заполнять исходные данные по группам:
длину линии по плану, пол/потолок, количество потребителей. Хотелось автоматически пробрасывать это из чертежа AutoCAD:

- трассы кабелей нарисованы полилиниями на планах;
- работа идёт через видовые экраны листов, в каждом включены свои слои (розеточная сеть, освещение и т.д.);
- номер группы (номер линии) указан на мультивыноске, стрелка которой стоит на кабеле;
- тип линии полилинии определяет способ прокладки (гофра ПВХ / гофра ПНД / лоток).

Итог — LISP-команда `DLN`, которая из открытого чертежа по активному видовому экрану считает длины и потребителей
по группам и пишет их в таблицу, а также помечает на чертеже спорные выноски/трассы.

### Мозговой штурм (27.09)

Предложено и решено:
- **Принято — проверки чертежа:** навигатор по пометкам, разрывы трасс, «трасса не доходит до щита», сверка номеров с таблицей
  в обе стороны, кириллица/латиница в номерах (К/K, С/C, Р/P, Е/E, Т/T, Н/H, А/A, В/B, М/M, О/O, Х/X) — только пометка, правит пользователь.
- **Отложено — журнал изменений** (лист «DLN_Журнал» с было/стало по группам): «с таблицей пока не работаем, только экспорт».
- **Отклонено — вертикальные участки по «H=» из выносок:** выноски есть не всегда, высота не всегда известна, бывает лоток.
- **Отклонено — обратная запись в чертёж** (номер группы в атрибут `ГРУППА` блоков, `COUNT` засечек, марка кабеля на план).
- **Принято на будущее — заполнение лотка:** когда у группы выбран кабель, диаметр из `Кабель_диаметр` (`Справочная_потребители!T4:X503`),
  участки лотка — слой `0_UNC_0 Лоток`; % заполнения по участкам и пометки перегруженных. Делать на объекте с лотком.
- **Несколько щитов:** группа относится к щиту, у которого начинается её трасса на плане; DLN будет писать группы каждого щита
  в таблицу этого щита (в соседнем чате решено: отдельная таблица на щит, питание ВРУ → ЩР → этажные щиты).
- **Настройки проекта в таблице — не нужны:** служебные числа (допуски, строка 21, блоки 15+2) остаются в начале LISP,
  в чертеже хранится только путь к таблице.

## Принятые решения

- Расчёт по **активному видовому экрану** (курсор внутри ВЭ на листе); учитываются только слои, не замороженные в этом ВЭ
  (коды 341 и xdata ACAD 1003) и не выключенные/не замороженные глобально. Подрезанные ВЭ — по контуру подрезки.
- Группа определяется мультивыноской: первая строка текста → номер линии (`R.1.05.10`, `К.1.01.1-(К.1.1)` → `К.1.01.1`).
  Стрелка должна лежать на полилинии той же системы (слой до последней точки: `0_UNC_3 Свет`), допуск 60 мм; иначе — по номеру системы `0_UNC_N`.
- Продолжение трассы: полилиния без выноски, у которой конец совпадает с концом полилинии группы (60 мм), но не в узле 3+ концов (щит).
- Длины: `Continuous` → колонка «DWG: гофра ПВХ по плану, м», `JIS_02_0.7` → «DWG: гофра ПНД по плану, м». Прочие типы — в примечание.
- `I` = сумма ПВХ+ПНД, округлённая вверх; `S` ставится по преобладающему типу, только если пустая; формулы K/L — см. `output/excel_formulas.txt`.
- Кол-во потребителей `G`: блоки со слоёв `*Оборуд*` той же системы, через которые проходит трасса группы (допуск 150 мм);
  ничья → ближе вершина → ближе стрелка; блок у 5+ групп (щит) не считается; дубликаты — один раз.
- Доп. информация: весь текст выноски без номера → колонка с «выноск» в заголовке (строки через пробел, разные выноски через «; »).
- Строки: с 21-й, блоками по 15 + 2 пустые, по порядку номеров (префиксы: Ввод, KV, На ИБП, От ИБП, R, RС, В, ТП, ЭK, EK, TE-ТП, TE-O, TE, SH, L, DALI, LD, LED, АПС, РЕЛЕ, К, K, ПУ, ПВ, КМН, УВ, ПН, WD, КУП, PE).
- Таблица не сохраняется автоматически; подъём между уровнями и вертикали пользователь учитывает сам.

## Открытые вопросы и следующие шаги
