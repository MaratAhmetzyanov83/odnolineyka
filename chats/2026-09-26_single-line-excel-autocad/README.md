# Однолинейная схема щита: Excel → AutoCAD (SX_Schema)

Чат 26–27.09.2026. Пилот — щит ЩР, «Сколково Парк» (№ 25-ЮН-ИНЖ 37/ПИР-30М). Второй объект — ЖК «Остров», щит ЩР ЭОМ.

## Задача

Марат проектирует щиты для умного дома. Он хотел заполнять данные щита **один раз в Excel** — шина → автомат → аппараты → модуль и канал → клемма → кабель → линия, — а однолинейную схему **вместе с нижней таблицей** строить в AutoCAD одной командой. Схема должна строиться из **его блоков** (`02_Однолинейка.dwg`) и выглядеть как его ручной чертёж.

По ходу чата добавились задачи:
- проверить расчёты в его таблице и подставлять номиналы автоматов по типу потребителя (розетки 16 А, свет 10 А);
- видеоинструкция по работе с таблицей;
- подсчёт автоматов, аппаратов, модулей и клемм для спецификации, свободные каналы модулей;
- удобство работы: каталог оборудования с многоуровневыми выпадающими списками, «светофор» ошибок, защита формул паролем, спецификация с артикулами, бирки `QF1/XT1`, команда перестроения без окна;
- ревизия всей книги: что убрать, что объединить;
- как правильно считать электроустановку, если на объекте несколько щитов (многоуровневое питание).

### 2. v3 — лист «Однолинейка» + SX_Schema.lsp
Новый лист «Однолинейка» (порядок столбцов слева направо = порядок на схеме сверху вниз):
`A` Щит, `B` № места, `C` Лист (авто), `D` Шина, `E` Автомат (`авто` или текст `1P C16A`), `F` 30 мА, `G` QF (авто), `H` Автомат итог, `I–K` Аппарат 1–3 (БП, Т, МК, КМ), `L` Модуль (ввод) → `M` Модуль, `N` Канал (пусто / № / `+` / `=` / `р` / `б` / `к`), `O` Канал №, `P` Клемма, `Q` Кабель, `R` Линия, `S` Наименование, `T` Р, кВт, `U` Ток, `V` Фаза, `W`/`X` проверки, `Y` Режим (`вручную`), `Z–AD` служебные, `AF–BA` скрытые расчётные (`AH` модуль гр., `AI` модель гр., `AJ` QF нач., `AL` код, `AR` фаз гр., `AS` 30 мА гр., `AW` модуль нач., `AY` клемма, `BA` БП/тр-р), `BB` мин. автомат по типу, `BC1` = `SX_DATA` (по этой метке LISP находит лист), `BD–BL` столбцы для LISP (draw, bus2, rcd, chtype, dev1–3, sym, hasline), `BM–BT` помощники подсчёта, `BU/BV` статус/№ линии, `BW` клемм 3L, `BX` доп. проходных, `BY` УГО (рус).

LISP `SX_Schema.lsp` + окно `SX_Schema.dcl` (в Windows-1251): читает Excel через COM (`A3:BL1000`), рисует таблицу → листы и шины → группы (автоматы, аппараты, гребёнка, N) → модули → строки (каналы, клеммы, PE, УГО).

## Принятые решения

1. **Схему строит LISP по листу «Однолинейка»** из блоков пользователя. Блок импортируется из `02_Однолинейка.dwg`, если его нет в чертеже; если нет и там — рисуется заменитель `SX_*`. Всё построенное лежит на слоях `SX_*`: `SX_LINES`, `SX_BLOCKS`, `SX_TABLE`, `SX_N`, `SX_PE`, `SX_KNX`, `SX_TEXT`, `SX_BOUND`.
2. **Команды**: `SXDRAW` (окно: файл, лист, щит, «Указать точку», библиотека), `SXUPDATE` (без окна, читает открытую книгу Excel), `SXCLEAR`, `SXBLOCKS`. Ожидаемое сообщение при загрузке: `[SX_Schema v3.7] SXDRAW / SXUPDATE / SXCLEAR`.
3. **Нельзя трогать исходную структуру книги Марата**: не добавлять строки, не вставлять столбцы, не трогать синие ячейки. Новое — в новых листах и свободных столбцах. Файлы, открытые в Excel, не перезаписываем — каждая версия под новым именем.
4. **Номиналы**: итог = max(по току, «Мин. автомат» по коду, ручной автомат); розетки 16 А, свет 10 А; перед БП/трансформатором минимум 10 А (`Справочник_схемы!B5`).
5. **Каталог** (лист «Каталог»): A Категория, B Производитель, C Модель, D Префикс, E Каналов, F Тип каналов, G Наименование, H Артикул, I Полюса, J Номинал, K 30 мА, L Ширина (мод. DIN), M Ед., **N По однолинейке (авто)**, **O Вручную / запас (+)**, **P Итого в спецификацию**. Настройки R4:S9: производитель автоматов = `Chint`, аппаратов = `(все)`, модулей = `(все)`, клемма 3L = `VPR-2.5-3L-GY`, проходная = `VPR-2.5-QUATTRO-GY`, 3L на 4–5-жильную линию = 1. Порядок разделов — R12:R25: Корпус, Автомат, Дифавтомат, Аппарат, Модуль, Шины, Клемма, Провод, Прочее. Имя `Модули_спр` = `Каталог!$C$4:$F$500`.
6. **Спецификация** собирается сама: все позиции Каталога с P > 0, по разделам, без пустых строк, с номерами `1.1, 1.2…`. Корпус, шины и провод вносятся количеством в Каталог (столбец O). Подсчёт справа свёрнут. Старая ручная спецификация — на скрытом листе `Спецификация_до_v3.7`. Если модели из однолинейки нет в Каталоге — красное предупреждение в `Спецификация!C1`.
7. **Статус `AE`** (светофор): нет фазы, нет мощности, дубль клеммы, ошибки W/X, 5 жил на 1 фазе, розетка без 30 мА, потери > 4 %. Лист «Однолинейка» защищён паролем `sx`; для ввода открыты D, E, F, I, J, K, L, N, P, Y.
8. **Коды потребителей → УГО** — одна таблица в «Справочной», AU:AY: код (из P) / УГО по-русски / 30 мА / мин. автомат / трёхуровн. клемм на линию (**SH = 2**). Значки — `Справочная!BA:BC`: Розетка → `Розетка1` → SOCKET; Светильник → `$RECOVER_230831092053-0` → LAMP; Сервопривод → `Сервопривод-1` → SERVO; Клапан → `EK.1` → VALVE; Привод (двигатель) → `Привод` → MOTOR; Нагреватель → HEAT; Прочее → BOX. Свой значок: название + имя блока, код пустой — LISP v3.7 вставит этот блок из библиотеки. Имена: `УГО_спр` = `Справочная!$AU$4:$AY$72`, `УГО_блоки` = `Справочная!$BA$4:$BC$30`.
9. **Клеммы**: один номер XT на линию. Число трёхуровневых = по коду (AY) или, если кабель 4–5 жил, из настройки `Каталог!S9`; доп. проходные = жилы − 3 × трёхуровн.
10. **Бирки**: лист «Бирки», столбцы C `QFD1/XT1` и D бирка кабеля (= линия, например `R.1.01.1`) — для печати.
11. **Несколько щитов**: у Марата отдельная таблица на каждый щит — так и оставляем. Питание бывает многоуровневым: ВРУ → ЩР → щиты этажей.
