## 3. Что проверено и верно

- Iр линии (Кс = 1 — так по нормам для групповых линий).
- In автомата: запас 10 % (In ≥ Iр / 0,9).
- Сечение по току: In ≤ Iдоп·Кп (ГОСТ Р 50571.4.43), ПУЭ табл. 1.3.6, 4–5 жил × 0,92 (ПУЭ 1.3.10).
- ΔU: формула ГОСТ Р 50571.5.52 прил. G, ρ = 0,0225 (медь при рабочей температуре), x0 по сечению.
- Кс быт: таблица и линейная интерполяция; Кс нижних щитов не перемножается.
- Рр = Руст.быт·Кс + Ко·Σ(P·Кс)сил + Рпост. «Расчёт_нагрузок» совпадает с «Нагрузка_щитов» (есть сверка).
- КРМ: tg φ 0,35, порог 50 квар.
- Iкз min: c = 0,95, ρ = 0,0263, переходные 0,015 Ом на щит. Iкз max: c = 1,05 (ГОСТ 28249).
- Термическая стойкость питающего кабеля: k = 115 (Cu) / 76 (Al).
- Категории надёжности: требуемая ≤ обеспеченной.

Номера пунктов СП 256 и значения таблиц — сверить с действующей редакцией.
В заголовке BF указан СП 256 п. 8.23 (3 % / 4 % от ВРУ) — проверить по тексту СП.

## 4. Предложение: workflow «три уровня»

Инженер вводит только то, что знает. Остальное — авто, со светофором.

| Уровень | Ввод инженера | Считается | Стадия |
|---|---|---|---|
| **Линия** | код, мощность, фазы, длина (DLN) | Iр, In, сечение (ток + остаток ΔU), Iкз, УЗО, статус | Р |
| **Щит** | тип объекта (1 раз), питание (связь или вручную) | Руст по группам, Кс по таблицам (быт / сил по числу двигателей / пост), Рр, Qр, Iр, перекос, КРМ, вводной аппарат, питающий кабель | П (ВРУ, ГРЩ) и Р |
| **Объект** | дерево щитов (связи), Iкз на вводе из ТУ | Рр ВРУ, категория, таблица нагрузок для ПЗ | **П** |

Правила, чтобы не перегружать:
1. Кс руками не вводить. BA — только как ручная замена, с жёлтой подсветкой «ручное».
2. Каждая проверка — одна строка статуса: что не так и что сделать.
3. «Пульт»: один блок «Расчёты» — зелёный / жёлтый / красный по каждой проверке (ток, ΔU, КЗ, категория, перекос, КРМ).
4. Пустые данные = жёлтый «не проверено», а не пусто.
5. Режим «Стадия П»: показывать только уровень «Объект» и щиты ВРУ/ГРЩ.
