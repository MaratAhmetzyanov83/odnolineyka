## Как собрать

```
py scripts/make_build_v5.py      # build_v5.py из ядра build_v4.py + новых частей
py scripts/build_all.py          # 4 книги в out/ (журналы out/build_*.log); можно: build_all.py demo ostrov
py scripts/video/make_video_v5.py            # видеогайд 4_Инструкции/Видеогайд_v5.mp4 (+ .srt) из out/ примера «все случаи»
py scripts/video/make_video_v5.py --frames   # только кадры во %TEMP%\sx_video_v5 (проверить рамки, без озвучки)
```

Для видео: ffmpeg в PATH, PyMuPDF, Pillow, голос Microsoft Irina (SAPI).

Нужно: Excel 365; в Центре управления безопасностью включено «Доверять доступ к объектной модели проектов VBA» (макросы записываются в книгу).

## Что сделано на этапе 1

- **«Линии»: 20 видимых столбцов** (14 ввода + 6 результатов), редкое — в «Ещё» (кнопка «+»), служебные скрыты.
- **Серое и синее:** во вводе формула `=Линии[@[_авто …]]` (серый курсив), своё значение — синее; стёрли — макрос возвращает формулу.
- **«Группа»: «гр»** — линия на автомате строки выше. Отдельный столбец, а не «Автомат»: иначе цикл (автомат фидера → Iр щита → фазы → снова автомат). «гр», вписанное в «Автомат», макрос переносит в «Группу». «=» в Excel не ввести (начало формулы).
- **Автоподбор:** автомат (ток группы, минимум кода, БП, полюса, утечка), сечение (Iдоп ≥ In группы, ΔU, Iкз), марка и жилы по коду, мощность по «кВт на шт», ввод щита — нагрузка щита.
- **Фазы:** расклад по щиту целиком — ручные и 3ф заданы, группы по убыванию мощности на наименее нагруженную фазу (`Щиты[_фазы авто]`); ручная фаза читается через ISFORMULA (не создаёт цикла).
- **Подбор без циклов:** ΔU и Z до шин для подбора — по сечениям фидеров «по току» (`Щиты[ΔU до шин (подбор), %]`), точная проверка — в «Замечаниях».
- **Кнопки щитов** (срез Excel) и **карточка щита** (A1: SUBTOTAL(103) по видимым строкам).
- **«Коды» = типовые потребители:** + кВт на шт, характеристика, вид аппарата утечки, управление, аппараты. **«Экспликация»** (по желанию). **«Объект»:** наименование (№ помещения / экспликация), «пом.», марка для пожарных.
- **Макросы книги:** восстановление серых, перенос «гр», починка формул после вставки/удаления строк (+ кнопка «Починить формулы»), на время работы книги выключено «заполнять формулы в таблицах».
- **Вводной узел:** «Листов под вводной узел» на щит (по умолчанию 1 = 17 мест); строки «вручную» не берут номера клемм.
- **DLN:** окно выбора файла показывает .xlsm.

## Пункт 1 после мозгового штурма 2: структура (04.10.2026)

- **Порядок листов:** ввод — Объект, Щиты (+ таблица «Шины» справа), Линии, Коды; результаты — Проверка, Щит, Кабельный_журнал, Спецификация, Бирки; справка — Гайд, Каталог, Методика, Таблицы_норм; в конце — Режимы, Расчёт_нагрузок; служебные скрыты.
- **Лист «Щит»** (вместо «Итоги_щитов»): выбор щита в C3; таблица под схемой (строка на место, шаг 20 мм) и итоги по каждому вводу: категория, Руст, Рр, Iр, cos φ, Кс, L1р–L3р. Линии — по шине и секции, нижние щиты — по фидеру, шина ИБП — к вводу из «ИБП от».
- **Категории только у вводов:** у линий столбцов категории и проверки нет; категория ввода — ручная или по шине (ИБП/ДГУ — I особая).
- **«Мест под вводной узел»** — настройка щита (пусто = 17, весь первый лист). При переносе из v3.12 — по первой линии после вводов и ИБП.
- **«Коды» = коды и УГО одной таблицей** (+ дифзащита, мин. автомат, клеммы 3L); на том же листе — Этажи, Кабели, Экспликация.
- **«Питается от»** — один столбец (серое по фидеру, синее — своё; стёрли — макрос листа «Щиты» возвращает серое); «Утечка, мА» — в «Ещё».
- Перенос данных: текст вместо мощности («кВт») и ручной ноль у ввода отбрасываются — остаётся серое.

## Пункт 2: документы и выгрузка (04.10.2026)

- **Кабельный журнал** по щиту (E1, «все» — объект): раскладка отдела + числа гофры (Ø, м), сводки: кабели (запас L1 = 20 %, вверх до 10 м), гофра по диаметрам (вверх до бухты), лоток, **сводка ПТО** (кабель + потолок/пол → артикул). Ввод щита не дублирует фидер.
- **Справочник диаметров** дополнен при сборке: сечения от 10 мм², FRLS, ВБШв, МКЭШ, слаботочка (ориентировочно, по каталогам).
- **Спецификация** по щиту (D1): раздел 1 — корпус вручную (таблица «Спец_вручную») + аппараты по «Каталогу» + то, чего в «Каталоге» нет (с пометкой); раздел 2 — кабели по марке (от крупных), гофра, крепёж по таблице «Нормы_расхода» (по умолчанию — как в «Жуковке»).
- **Выгрузить для AutoCAD** (кнопка на листе «Щит», макрос SX_ExportAutoCAD): «<книга>_AutoCAD.xlsx» рядом с книгой, на щит — листы «схема», «итоги», «журнал», «спец» (значения; имена постоянные для Data Link).
- **Ток утечки** по ПУЭ 7.1.83 (0,4 мА/А + 10 мкА/м, у группы — сумма; > 1/3 IΔn — замечание) и **Lмакс по КЗ** — результаты в «Ещё» (вид столбца «xc»).

## Пункт 3: LED 24 В (04.10.2026)

- Линия до 50 В (напряжение по коду или в «Ещё») — **постоянный ток**: I = P/U, ΔU = 2·ρ·L·I/S от выхода БП, допустимо 5 % («Объект» C14); сечение — по току линии и потерям, без Iкз; жил по умолчанию 2.
- **Группа под автоматом БП**: строка автомата с «МК-5-1; БП 24V 480W» (+ диммер в «Модуле»), линии 24 В — «гр». Автомат — по стороне 230 В.
- **Проверка БП**: мощность и напряжение из названия; нужно = 1,3 («Объект» C13) × Σ (U + ΔU)·I — как «Расчет_БП» v1.05; в «Ещё» — «БП: нужно, Вт» и «Uвых БП, В».
- **Ток канала диммера**: «Каталог», столбец Q «Ток канала, А»; линии на одном канале суммируются.
- Пример «все случаи»: щит ЩБП (БП 480 Вт на 4 канала DALI, БП 75 Вт — мал).
- Поправка длины: пустое «Кол-во потребителей» = 1 опуск (раньше опуск вычитался).

## Пункт 4: модули, УЗО на группу, порядок, выдача, наклейки (04.10.2026)

- **Модули по умолчанию** («Объект», таблица «Модули_умолч»): «Модуль» — серое/синее; подряд идущие линии с одним управлением → модуль модели по умолчанию, новый — когда каналы кончились; шторы — 2 выхода, DALI — шина (0 каналов). Свои блоки модулей — как раньше.
- **УЗО на группу**: строка «УЗО.1» (код «УЗО», «УЗО 2P 40А 30мА» в «Аппаратах»), линии «узо» в «Группе». Автомат строки УЗО — по току блока, линии — обычные автоматы; проверки номинала УЗО и тока утечки блока; блок 2P — одна фаза.
- **Макросы**: «Упорядочить щит» (узел на месте; по управлению, коду, помещению; блоки не рвутся), «Закрепить фазы», «Зафиксировать выдачу» (снимок на скрытый «_выдача», предлагает закрепить фазы), «Наклейки (A4)» (лист «Наклейки», ячейка = модуль DIN, 18 мм на бумаге — ширина подгоняется под принтер; рейка длиннее A4 — несколькими полосами с подписью «Рейка N»).
- **Лист «Изменения»**: добавлено / удалено / было → стало по щитам и листы схемы; подсветка в «Линиях».
- Найдено: NumberFormat «dd.mm.yyyy» портит стили файла (книга не открывается) — даты через NumberFormatLocal; Names.Add разбирает формулу по-русски — имена с функциями через RefersToLocal.

## Найдено по ходу

- Excel видит циклические ссылки только при реальном расчёте (ветка IF, которая не выполняется, цикла не даёт); ISFORMULA цикла не даёт.
- Запись массива в столбец таблицы, где первая ячейка — формула, затирает ручные значения → ручные значения пишутся по ячейкам.
- Имена в LET вида ph3, f3, fx1, m1, d1, s1, r1 Excel принимает за адреса (формула не записывается); повтор имени в одном LET — тоже ошибка.
- Таблицы Iдоп_2ж/3ж на строку короче Iдоп_S — массивы в подборе обёрнуты IFERROR.
- **Печать шире экрана.** Ширина столбца — в символах шрифта «Обычный», а метрики шрифта у принтера свои: Calibri 11 при экране 125 % печатается на ~4,4 % шире `Columns().Width` (при 100 % экрана больше, при 150 % меньше); свободные фигуры — тоже. В режиме «Разметка страницы» `Width` = печатная ширина, но округлена до экранного пикселя (0,6 пт). Наклейки: коэффициент — по одному широкому столбцу (разметка / обычный вид), затем смесь двух соседних экранных ширин — все границы в пределах ±0,12 мм от сетки 18 мм. Видео: масштаб снимков — по сетке служебной книги с тем же шрифтом (сетку на залитых ячейках Excel не печатает).
