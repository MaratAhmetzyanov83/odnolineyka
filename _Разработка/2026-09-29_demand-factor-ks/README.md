# Коэффициент спроса (Кс) по СП 256 — однолинейка v3.9 + ГРЩ‑ЖД резиденции

Чат 29.09.2026. Продолжение проекта `chats/2026-09-26_single-line-excel-autocad` (шаблон и пример v3.8).

## Задача

1. «Как правильно посчитать коэффициент спроса для щита на примере моих таблиц» — разобрать лист «Нагрузка_щитов» (пример ЖК «Остров»).
2. «А как с такой таблицей быть? Это резиденция, здание жилого дома» — ГРЩ‑ЖД (два ввода, секции 1/2, аварийный режим, ~20 отходящих щитов, Руст ≈ 524 кВт).
3. «Занести это всё в нашу разработанную однолинейку и с этими правками по Кс» — сделать расчёт Кс в шаблоне v3.8 и перенести в него ГРЩ‑ЖД.

## Что нашли

**Пример v3.8 (ЖК «Остров»), «Нагрузка_щитов»:**
- Кс = 0,5 вбит руками; по таблице для Руст = 4,98 кВт должно быть 0,8.
- Блоки 2 и 3: `Iр = V15/0,38/1,732/V17*V18` — Кс применён дважды (V15 уже = Руст·Кс).
- Блок 1: cos φ = 0,95 константой (в блоках 2–3 — средневзвешенный).
- Iр по симметричной формуле, хотя фазы нагружены неравномерно.
- **Строки 3–6: стёрты формулы F, G, H** (фаза и мощность) — первые четыре линии (R.1.01.1, R.1.02.1, R.1.03.1, R.1.03.2) не попадали в Руст. Было и в шаблоне.
- «Исходные данные» P (cos φ): неизвестный код потребителя → #Н/Д (и дальше по цепочке: Z, потери).

**ГРЩ‑ЖД:**
- Кс задавался на каждую линию, Кс секции — средневзвешенный. Схема верная, значения — нет: одна таблица Кс «по Руст» (квартиры повышенной комфортности) для ГРЩ не подходит, половина мощности — инженерия.
- **У ЩУОВ, ЩР‑ПК, ЩС‑ВК.002/.003 Кс записан текстом «0.7» (с точкой)** → `N()` даёт 0 → подставлялся Кс = 1. Поэтому секция 1 = 187,4 кВт (с числом 0,7 было бы 151,3).
- Блок «Сводный»: cos φ = 0,5 (W44) → Iр 977 А вместо ~514 А; Кс 0,5 в W45 нигде не используется.
- Секции задавались по строкам листа нагрузок (E) — съедут при изменении порядка линий.

## Принятые решения (v3.9)

1. **Группы нагрузки** (столбец «Группа Кс»):
   - **Быт** — бытовая нагрузка дома/квартиры (розетки, свет, тёплый пол, кондиционеры, бытовые ЩР). Кс — по таблице «квартиры повышенной комфортности» (СП 31‑110 табл. 6.2 = СП 256: до 14 кВт 0,8; 20 — 0,65; 30 — 0,6; 40 — 0,55; 50 — 0,5; 60 — 0,48; 70+ — 0,45) по **сумме Руст быт щита**, линейная интерполяция. Кс нижних щитов не перемножается.
   - **Сил** — силовая, свой Кс линии («Исходные данные» BA; пусто = 1). Вентиляция/насосы — по табл. СП 256 для сантехнического и вентиляционного оборудования (по числу двигателей, резервные не учитываются), пищеблок — по табл. для теплового оборудования.
   - **Пост** — Кс = 1 и без Ко: обогрев кровли/воронок, слаботочка, АСУ, питание KNX, СПЗ.
   - **Нет** — не учитывается: вводы, резерв, транзит.
2. **Рр = Руст.быт·Кс(табл.) + Ко·Σ(Pсил·Кс) + ΣPпост**, Ко = 0,9 (как в СП 256 для жилого дома: Рр = Ркв + 0,9·Рс). Кс итоговый = Рр/Руст → идёт в V9 и в «В Акад».
3. **Iр** — по наиболее нагруженной фазе: `max(Pф.max·Кс/(0,22·cos φ); Рр/(√3·0,38·cos φ))`.
4. **Секции**: «Исходные данные» BB (1/2, пусто = 1) — по номеру линии, а не по строке листа. В каждом блоке «Нагрузки_щитов» считается «Весь щит (аварийный)», «Секция 1», «Секция 2».
5. Группа по умолчанию — по коду потребителя: «Справочная» AZ4:AZ51 (рядом с таблицей кодов P). Ручная — «Исходные данные» AZ (список). Кс числом с точкой/текстом — красная подсветка BA.
6. Структуру книги не ломаем: новые столбцы только в свободных местах (правило «не вставлять столбцы»).

## v3.11 — связи однолинеек (вышестоящий ↔ нижестоящий щит), питание щита, ТКЗ по линиям, данные для ПЗ

Запрос: «ну давай всё делай, главное сильно не перегружать, чтобы было удобно инженеру» + «нужна возможность подключать другие однолинейки как нижестоящий щит». Скрипт `output/scripts/patch9.py` (out10 → out11).

**Решение по связям — без макросов, стандартной «Специальной вставкой → Вставить связь» Excel** (внешние ссылки; при открытии Excel предложит обновить связи; файлы не переименовывать — иначе «Данные → Изменить связи»):
- **«Нижестоящие_щиты»** (в файле вышестоящего щита): строка на линию‑фидер (B — номер линии). D:J — связь с разделом 4 «Питание_щита» нижестоящего файла: Руст, Руст быт, Руст сил, Рр сил (Σ P·Кс), Руст пост, cos φ, Iр. K:N — для нижестоящего: ΔU от ВРУ до его шин, Zпетли и Iкз max на его шинах, In фидера. O — проверка фидера (Iр ≤ In, термостойкость, «нет связи»).
- Линия со связью получает группу **«Щит»**: её Руст быт идёт в общий Руст быт (Кс по таблице пересчитывается по сумме), Рр сил — в Рр сил (Ко = 0,9 применяется один раз — наверху), постоянная — в постоянную. Ток линии и cos φ — из нижестоящего (Iр, не установленная мощность), мощность в «Однолинейке» — Руст нижестоящего. Многоуровневость работает рекурсивно (экспорт уже содержит всё ниже). Пока связи нет — линия считается как обычная.
- **«Питание_щита»**: 1) импорт от вышестоящего (связь с K:N) или 2) питающая линия вручную (от ВРУ/ТП: ΔU и Iкз на шинах питающего, трансформатор, кабель, аппарат). 3) Результат: ΔU от ВРУ до шин → в каждую линию; Zпетли на шинах → Iкз в конце каждой линии; Iкз min/max на шинах; проверки питающей линии: Iр ≤ In ≤ Iдоп, отключение (ПУЭ 1.7.79, ≤ 5 с), термостойкость t доп = (k·S/Iкз)², селективность (ориентир In ≥ 1,6·In отходящего). 4) Экспорт этого щита для вышестоящего. 5) Настройки КЗ: ρ нагретых жил 0,0263 (Cu)/0,042 (Al), переходные 0,015 Ом на щит, c_min = 0,95.
- **По линиям** («Исходные данные» BH:BM): BH — К прокладки на линию (пусто = общий), BL — Zпетли в конце, BI — Iкз min, BJ — Iкз/In (In — автомат группы из «Однолинейки»), BK — отключение ≤ 0,4 с (B 5·In, C 10·In, D 20·In; если в группе 30 мА — «ok (УЗО 30 мА)»), BM — Iкз max. «Однолинейка» AE: «Iкз мало — отключение > 0,4 с». «ΔU до шин щита» из «Справочной» убран — теперь с листа «Питание_щита».
