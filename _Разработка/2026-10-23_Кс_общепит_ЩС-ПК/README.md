# Кс для профессиональной кухни (общепит) — решение 23.10.2026

Объект: 098 Ташкент-КТ, Том 1 ЖД, щит **ЩС-ПК** (проф. кухня, цокольный этаж), питание от ГРЩ-ЖД (линия ЩР-ПК).

## Проблема

В книге v3.12 все линии кухни имеют код `R` → группа «Быт» («Справочная» AZ). Для «Быт» Кс берётся из
графика бытовой нагрузки по Руст щита (`Кс_Р` / `Кс_К`): при Руст 105 кВт → **Кс 0,45**, Рр 47,4 кВт.
Этот график — для квартир и розеточной сети. Для технологического оборудования общепита он не применяется.

## Норма

СП 256.1325800.2016 (ред. с изм.), раздел 7.2 «Нагрузки общественных зданий»:

| Пункт / таблица | Что говорит |
|---|---|
| табл. 7.8 | технологическое оборудование общепита и пищеблоков — по табл. 7.9 и п. 7.2.9 |
| **табл. 7.9** | Кс по **числу электроприёмников теплового оборудования** на элементе сети: 2 — 0,9; 3 — 0,85; 5 — 0,75; 8 — 0,65; **10 — 0,6**; 15 — 0,5; 20 — 0,45; 30 — 0,4; 60–100 — 0,3; > 120 — 0,25 |
| примеч. 1 к табл. 7.9 | в технологическое входит тепловое, механическое и мелкое холодильное (единичной мощностью < 1 кВт) оборудование |
| примеч. 3 к табл. 7.9 | мощность посудомоечных машин в максимуме нагрузки **на вводах не учитывается** |
| п. 7.2.8, табл. 7.10 | линия технологии + посудомоечных: Рр = Рр.пм + 0,65·Рр.т, но не меньше Рр.т; 1 машина — Кс 1 (холодная вода) / 0,65 (горячая) |
| п. 7.2.9 | ввод общепита: Рр = Рр.т + 0,6·Рр.с.т (Рр.с.т — сантехника и холодильные машины) |
| табл. 7.12 | cos φ полностью электрифицированного общепита — 0,98 |

Те же формулы и таблицы — СП 31-110-2003, п. 6.20–6.21, табл. 6.8, 6.10.
Источники: [СП 256 — meganorm.ru](https://meganorm.ru/mega_doc/norm/pravila/0/sp_256_1325800_2016_svod_pravil_elektroustanovki_zhilykh_i.html),
[СП 31-110 — sonel.ru](https://www.sonel.ru/ru/biblio/knowledge-centre/standards/SP_31-110-2003/assumed_load/).
Значения табл. 7.9 / 7.10 совпали с `ElEngineeringAppV1` (`normative_demand_extended.py`, `_TABLE_79_POINTS`, `_TABLE_710`).

## Расчёт ЩС-ПК

- Тепловое оборудование (n = **10**): 90 пароконвектомат 30,5; 108 плита 14,0; 101 жарочная 10,8; 103 фритюрница 6,0;
  107 макароноварка 5,4; 98 печь томления 4,2; 96 термостат 2,0; 117.1 шкаф тепловой 0,77; 58 чайник 2,4; 56 СВЧ 1,6 кВт → **Кс 0,6**.
- Руст технологии = 88,26 (спецификация ИПИТА, без котломоечной) + 6,86 (доп. посты листа 3 и резервы) = **95,12 кВт**.
- Котломоечная 69 (10,2 кВт, 1 шт.) — на вводе не учитывается (примеч. 3); её линия считается по своему Р (Кс 1).
- Сантехники и холодильных машин > 1 кВт нет (моноблоки камер 0,57–0,81 кВт — «мелкое холодильное», в технологии) → Рр.с.т = 0.
- **Рр = 0,6 × 95,12 = 57,1 кВт** (≥ Рmax 30,5). Iр = 57,1 / (√3 · 0,4 · cos φ): 84 А при 0,98, **87 А при 0,95** (в книге — 0,95, с запасом).
- Вариант «СВЧ и чайник персонала — не тепловое кухни»: n = 8, Кс 0,65, Рр 61,8 кВт. Не принят: это тепловые приёмники того же щита.

## Как сделано в книге (без изменения шаблона)

«Исходные данные» BA (Кс для «Сил», ручной) = **0,6** на всех линиях R ЩС-ПК, **0** — на котломоечной R.0.07Б.3(69).
Число в BA переводит линию в группу «Сил» (BC). Ко 0,9 не применяется — в щите нет «Быт».
Итог щита: Рр = Σ Р·0,6 = 57,1 кВт. Автоматы и кабели линий считаются по своему Р (BA на них не влияет).

## Результат (сделано 23.10, книги на сервере)

| | До | После |
|---|---|---|
| ЩС-ПК Руст / Рр | 105,3 / 47,4 кВт (Кс 0,45 «Быт») | 105,3 / **57,1 кВт** (Кс 0,6 «Сил», котломоечная 0) |
| ЩС-ПК Iр (наиб. нагруж. фаза) | 77,7 А | **93,6 А** |
| Фидер в ГРЩ-ЖД (QF10) | 3P C100, ВВГнг(А)-LS 5×35 | **3P C125, ВВГнг(А)-LS 5×50**, L 53 м, ΔU 0,97 % |
| Ввод ЩС-ПК (QS1) | QS 3P 100 А | **QS 3P 125 А** |
| ГРЩ-ЖД итог (Рр / Iр) | 320,2 кВт / 509,6 А | **328,6 кВт / 522,7 А** (секц. 1: 174,3 кВт / 275,2 А) |

Почему 5×50 / 125 А: при Iр 93,6 А книга подбирает автомат 125 А (ступень выше 100), а 5×35 от 125 А не защищён
(«КАБЕЛЬ НЕ ЗАЩИЩЁН»). 5×50 — ошибок нет, запас на прокладку в общем лотке.

Связи книг: в ГРЩ-ЖД основной путь на ЩС-ПК вёл во временную папку другого ПК (`C:\Users\user\…\scratchpad\w2\…`),
в ЩС-ПК — только на `\\Server\…`. Оба основных пути заменены на относительные (`../Проф. кухня…/…`, `../Таблицы/…`).
**Остальные 15 связей ГРЩ-ЖД так же ведут в чужой scratchpad** (работают только через запасной `\\Server\…`) — не правил.

## Котломоечная машина (поз. 69) — почему 0 на вводе

Winterhalter UF-M Energy, 10,2 кВт, 380 В, пом. 7 «Мойка кухонной посуды» — машина для мойки котлов, гастроёмкостей,
противней, т.е. посудомоечная машина по табл. 7.8 / 7.10.
- Примеч. 3 к табл. 7.9: мощность посудомоечных машин в максимуме нагрузки на вводах не учитывается
  (моют после приготовления, пик плит и пароконвектомата на них не накладывается).
- Проверка по п. 7.2.8 (если считать её на вводе как на питающей линии):
  Рр = Рр.пм + 0,65·Рр.т = 10,2 + 0,65·57,1 = 47,3 кВт < Рр.т 57,1 → берётся 57,1. **Результат тот же.**
- Её собственная линия (QFD5 4P C32, 5×6) считается по полной мощности 10,2 кВт — Кс 0 только в итоге щита.
- Запас: даже с котломоечной при Кс 0,6 (Рр 63,2 кВт, Iр ≈ 96 А) ввод 5×50 / 125 А проходит.

## Фазы (23.10, лист «Нагрузка_щитов», столбец E — ручная фаза)

Однофазные линии были L1 12,27 / L2 5,33 / L3 10,82 кВт, перекос 6,6 %, Iр по наибольшей фазе 93,6 А.
Перенесены 3 линии: 98 печь томления 4,2 кВт L1 → L2; 96 термостат 2,0 кВт L3 → L1; 46 льдогенератор + шкаф 0,62 кВт L1 → L3.
Стало: Руст по фазам 35,08 / 35,16 / 35,07 кВт, перекос 0,1 %, **Iр 86,9 А**.
При 86,9 А хватило бы 100 А и 5×35; оставлено 5×50 / 125 А — запас на прокладку в общем лотке и на изменения технологии.

Замечания (не ошибки расчёта, решить в проекте):
1. **Iкз max на шинах ЩС-ПК 5,87 кА** при отключающей способности модульных аппаратов 6 кА — запас 2 %.
   Надёжнее аппараты с Icu 10 кА или уточнить Iкз (если ГРЩ-ЖД ближе к ТП, ток будет выше).
2. **Селективность QF10 C125 (ГРЩ) → QFD C50** — только по номиналам (2,5 раза). При КЗ > 1250 А
   (мгновенный расцепитель C125) оба аппарата могут сработать — полная селективность не обеспечена (обычно для модульных).
3. **УЗО 30 мА на пароконвектомате 30,5 кВт и плите 14 кВт** — у техники с частотными преобразователями (вентилятор
   пароконвектомата, индукция) бывают токи утечки и ложные срабатывания; проверить по паспорту MKN тип УЗО (A / F / B).
   Для розетки 63 А требование 30 мА не обязательно (ГОСТ Р 50571.4.41, п. 411.3.3 — розетки до 32 А).
4. Iдоп по ПУЭ 1.3.7 «в воздухе»; в лотке пучком ПУЭ требует снижения только для отдельных случаев.
   По ГОСТ Р 50571.5.52 (метод E, перфорированный лоток, 3 кабеля вплотную × 0,82) 5×50 ≈ 148 А ≥ 125 А — ok.

## Решения по УЗО (23.10, пользователь)

- Пароконвектомат (поз. 90, 30,5 кВт, розетка 63 А 3P+N+PE): **автомат 4P C50 без УЗО** (NB1-63, 179750).
  30 мА обязательны для розеток до 32 А (ГОСТ Р 50571.4.41, п. 411.3.3); у мощной техники с ТЭНами и частотником
  30 мА дают ложные срабатывания. Книга показывает «розетка без 30 мА» — это правило шаблона (код R), не норма.
- Все дифавтоматы — **тип AC** (Chint NB1L 1P+N C16 — 203295, C25 — 203297; 4P C16/C25/C32 — 198111/198123/198131).
  Риск: тип AC не реагирует на пульсирующие токи утечки (СВЧ, индукция, электроника) — принято пользователем.
