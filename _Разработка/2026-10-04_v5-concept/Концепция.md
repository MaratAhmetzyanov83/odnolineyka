# Концепция новой книги однолинейки (рабочее название v5)

Дата: 04.10.2026. Основа — мозговой штурм с Маратом (около 30 ответов) и разбор беты v4.
Процесс, под который делается книга, — `Рабочий_процесс.md`. Расчёты и нормы остаются из v4 (`4_Инструкции/Методика_расчёта.md`).

## 1. Что мешает в v4 (замеры 04.10)

- 18 видимых листов; вводить данные нужно только на трёх.
- «Линии»: 42 столбца ввода, 33 видимых результата, ещё 132 скрытых. Столбцы ввода идут в порядке старых листов v3.12, а не в порядке мысли инженера.
- Много особых значков: `авто`, `=`, `р`, `+`, `б/к`, `-`, `вручную`.
- То, что спрятано в «ручных» столбцах, на деле вводят постоянно (ЖД: сечение руками у 98 % линий, автомат — у 58 %, фаза — у 42 %).
- Свой автомат у 82 % линий ЖД, а сейчас забытое `авто` без предупреждения сливает линию с группой выше.
- **Ошибка:** автофаза идёт по кругу по строкам, поэтому линии одной группы (один однофазный автомат) попадают на разные фазы.
- Скорость в порядке: ЖД (350 линий) пересчитывается за 0,25 с после правки.

## 2. Цель

После DLN инженер, в том числе новичок, за минимум действий получает готовый щит:
- строки заполнены и проверены;
- раскладка по местам, модулям, фазам и клеммам сделана;
- документы для сборки и снабжения готовы;
- изменения с прошлой выдачи видны.

## 3. Принципы

1. **Всё, что можно вывести, таблица выводит сама** — из номера линии, кода, числа потребителей, пометок выноски, экспликации.
2. **Одно правило ввода.** В белой ячейке серым курсивом — выбор таблицы. Вписали своё — синее, таблица проверяет. Стёрли — снова выбор таблицы.
3. **Короткая строка.** Около 13 видимых столбцов в порядке мысли: линия → что → сколько → чем защищаем → как управляем → каким кабелем → фаза и клемма. Редкое — в свёрнутой группе «Ещё».
4. **Строка = место на схеме.** Порядок строк = порядок на схеме.
5. **Ошибку видно сразу**, рядом — что сделать. Ошибиться трудно: списки, подсказки, защита формул.
6. **Щит на одном экране:** кнопки щитов и карточка щита над таблицей, лист «Щит» с лентой схемы.
7. **Документы собираются сами**, изменения с прошлой выдачи подсвечены.

## 4. Принятые решения

| Тема | Решение |
|---|---|
| Щиты в книге | Один список линий. Над ним кнопки щитов (срез Excel) и карточка выбранного щита |
| Автоподбор | Максимальный: тип аппарата, номинал, характеристика, отключающая способность, марка, жилы, сечение. Ручное значение — синее |
| Группа | Пусто = свой автомат; `=` = на автомате строки выше. Для SXDRAW таблица сама переводит в `авто` |
| Фазы | Автобалансировка **по автоматам**: группа и модуль от одного автомата — на одной фазе. Ручная фаза не меняется. Кнопка «Закрепить фазы» перед выдачей |
| Утечка | Ток (10/30/100/300 мА) и вид аппарата (дифавтомат / УЗО на группу / нет) — настройка кода в «Кодах» |
| УЗО на группу | УЗО стоит на основной шине; от него вниз-вправо идёт своя шина с названием УЗО; автоматы группы подключаются к этой шине |
| Мощность | По коду: кВт на потребителя × число из DLN (розетки 0,06 кВт × число); явная мощность — вручную |
| Наименование | По умолчанию «название по коду + номер помещения» (настройка: писать «пом.» или нет). Вариант «по экспликации»: лист «Экспликация», код помещения → название. Наименование идёт и на наклейки |
| Модули | Автораскладка по пометкам выноски (`Relay`, `DIM`, `DALI`, «с кнопки») и кодам (шторы, клапаны, LED); ручная правка |
| Вводной узел | На щит — «листов под вводной узел» (по умолчанию 1 = 17 мест, бывает 2). Строки узла не рисуются. SXDRAW начинает со следующего листа |
| Data Link | Выгрузка таблиц под схему по каждому щиту (для коллег, которые рисуют вручную) и журнала — в лёгкий файл кнопкой |
| Изменения | «Зафиксировать выдачу» → снимок; потом подсветка изменённого и лист «Изменения» для сборщика и снабжения |
| Макросы | В самой книге (.xlsm): кнопки на листах, ничего не нужно ставить |
| Пользователи | Отдел, есть новички: подсказки, списки, защита |

## 6. Лист «Линии»

Сверху (закреплено): кнопки щитов и карточка выбранного щита — питание, Руст, Рр, Iр, cos φ, ΔU до шин, Iкз, сколько мест и листов схемы, число замечаний.

### Видимые столбцы ввода

| Столбец | Пусто = выбор таблицы | Откуда берётся |
|---|---|---|
| Щит | — | вручную / DLN |
| Номер линии | — | DLN |
| Наименование | по коду + помещение (или по экспликации) | — |
| Кол-во потребителей | — | DLN |
| Р, кВт | кВт на потребителя по коду × кол-во | смежники, дизайнер |
| Автомат | подбор: тип, полюса, характеристика, номинал (`1P C16`, `АВДТ 1P+N C16 30мА`); `=` — группа | — |
| Утечка, мА | по коду | — |
| Управление | по пометке выноски или коду: Relay, DIM, DALI, шторы, клапан, нет | DLN (текст выноски) |
| Аппараты | по коду (LED → БП); несколько через «;» (`КМ NCH8; БП 24V`) | — |
| Кабель | марка + жилы + сечение по подбору (`ВВГнг(А)-LS 3×2,5`) | — |
| Длина, м | по плану + опуски × кол-во + запас | DLN |
| Фаза | автобалансировка по автоматам | — |
| Клемма | следующая по порядку; `нет` — без клеммы | — |

### «Ещё» (свёрнуто)

Питает щит (если номер линии ≠ имени щита), фазы и напряжение, группа Кс и Кс, cos φ, секция, шина (ИБП, ДГУ…), категория, пожарная, режим строки (узел / рисовать), модуль и канал вручную, № места (для пропусков), прокладка (лоток, ПВХ, ПНД — заполняет DLN), К прокладки, примечание.

### Результаты (справа)

Статус (в норме / что не так) · Iр, А · ΔU, % · Лист / место. Подробный расчёт — в скрытых столбцах и на листе «Разбор» (по шагам, с пунктами норм).

## 7. «Коды» — таблица типовых потребителей

Код задаёт всё по умолчанию; любую настройку можно переписать в строке.

Наименование · УГО · кВт на потребителя · опуск, м на потребителя · фазы и напряжение · cos φ · группа Кс · категория · пожарная · утечка, мА · вид аппарата при утечке (дифавтомат / УЗО на группу / нет) · мин. номинал (свет 10 А, розетки 16 А) · характеристика (B / C / D) · мин. сечение (свет 1,5, розетки 2,5) · марка кабеля (или по объекту) · жилы (по фазам или явно) · управление по умолчанию · аппараты по умолчанию · клемм на линию.

## 8. Автоподбор (цепочка)

1. Iр — по Р, напряжению, фазам, cos φ.
2. Вид и полюса аппарата — по коду и фазам (1ф: `1P` или `1P+N`; 3ф: `3P`; с утечкой — дифавтомат или УЗО по коду).
3. Номинал — наименьший из ряда ≥ max(Iр, мин. по коду), с учётом пусковых токов.
4. Характеристика — по коду (C по умолчанию; B, если иначе не проходит Iкз; D для тяжёлого пуска).
5. Кабель — марка по объекту и пожарности (LS; FRLS для пожарных линий); жилы по фазам и системе заземления; сечение — наименьшее ≥ мин. по коду, при котором:
   - Iдоп · Кпрокл ≥ In (ПУЭ 1.3.10, ГОСТ Р 50571.4.43);
   - ΔU ≤ допустимого (СП 256 п. 8.23, с надбавкой за длину);
   - Iкз в конце ≥ кратности для характеристики / отключение ≤ 0,4 с (ПУЭ 1.7.79).
   Если не проходит — следующее сечение.
6. Отключающая способность — по Iкз max на шинах (4,5 / 6 / 10 кА).
7. Артикул — из «Каталога» по бренду объекта → спецификация.

## 9. Раскладка щита

- **Вводной узел:** первые N листов щита (N из «Щитов»). Строки узла заполняются для расчёта и спецификации, на схеме не рисуются (если не указано «рисовать»). Линии начинаются со следующего листа.
- **Порядок:** порядок строк. Кнопка «Упорядочить щит»: узел → по управлению и модулям → по кодам и помещениям. Потом можно править руками.
- **Группы:** `=` в «Автомате».
- **Модули:** подряд идущие линии с одним управлением собираются в модуль; модель — по настройке объекта для этого вида управления (из «Каталога», с числом каналов); новый модуль — когда каналы кончились.
- **Клеммы:** по порядку.
- **Фазы:** по порядку строк каждому автомату (группе) — наименее загруженная фаза с учётом ручных и трёхфазных. Перед выдачей «Закрепить фазы», чтобы фазы не менялись от правок.

## 10. Изменения

1. «Зафиксировать выдачу» сохраняет снимок: номер ревизии, дата, ключевые поля каждой линии (наименование, Р, автомат, кабель, длина, фаза, модуль и канал, клемма).
2. В «Линиях» подсвечены ячейки, которые изменились после снимка; новые строки — отдельным цветом.
3. Лист «Изменения»: добавленные, удалённые и изменённые линии (было → стало), по щитам — для сборщика и снабжения.
4. Спецификация — подсветка изменений, как в SX_Spec.

| Спецификация (авто) | кабельные изделия щита (кабели по маркам + запас, округление вверх до 10 м; ПуГВ; гофра ПВХ/ПНД по диаметрам), крепёж по коэффициентам от длины, аппараты по схеме (из «Каталога»). Комплект корпуса — вручную |

| БП для LED | выбирает инженер, таблица проверяет нагрузку БП |
| Лист «Щит» | превью того, что уходит в AutoCAD по выбранному щиту: таблица под схемой + итоги по вводам (заменяет «Итоги_щитов») |
| Каталог и коды | стандарт отдела в шаблоне + правки под объект |

### Новая структура книги

- **Ввод:** Объект · Щиты (+ таблица шин) · Линии · Справочники (типовые потребители = коды и УГО одной таблицей, этажи, экспликация, кабели).
- **Результаты:** Проверка · Щит · Кабельный журнал · Спецификация · Бирки (+ наклейки).
- **Справка:** Гайд · Каталог · Методика · Таблицы норм.
- **В конце, по необходимости:** Нагрузки (таблица для ПЗ, режимы, ИБП).
- **Скрыты:** Однолинейка (для SXDRAW), Спецификация_авто, служебные.

Дубли убираются: итоги щита — только «Щиты» (строка на щит) и «Щит» (по вводам, под схему); «Утечка, мА» — в «Ещё» (видна в тексте автомата); «Питается от» на «Щитах» — один столбец (серое/синее).

## 17. DDECAD (ddecad.ru) — что взять (разбор 04.10.2026, по руководству пользователя)

DDECAD — надстройка Excel + AutoCAD с той же задачей: расчётная таблица щита (файл на щит: «Групповая таблица» + «Таблица нагрузок»), таблица ГРЩ с «расчётными группами» (секции, режимы, нагрузки вне максимума), отрисовка схем щита и ГРЩ в AutoCAD по кодам, «Обновить щит» в готовой схеме, автоподбор кнопкой, кабельные журналы по ГОСТ 21.608/21.613, спецификация кабелей, отдельные расчёты (ТКЗ по ГОСТ 28249, предельная длина, Кс освещения по табл. 7.6 СП 256, Iдоп по ГОСТ Р 50571.5.52, невозгорание по Ц-02-98).

**У нас уже так или лучше:** одна книга на объект без внешних связей (у DDECAD файлы щитов связаны формулами, «Подключить щит» и «Питающий щит» — кнопками; у нас фидер находится сам); автоподбор живой, серое и синее (у DDECAD — кнопкой, перезаписывает ячейки); фазы — автобалансировка по автоматам (у DDECAD — кнопки «Убрать перекос фаз», «Поменять фазы местами»); мощность — код × кол-во (у DDECAD матрица «Таблица нагрузок»: столбец на тип нагрузки, нужна для формы Ф636-92 — для жилья лишняя).
