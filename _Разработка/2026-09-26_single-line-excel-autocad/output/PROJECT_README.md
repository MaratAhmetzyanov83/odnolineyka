# Проект SX_Однолинейка — однолинейная схема щита из Excel в AutoCAD

Паспорт проекта. Здесь всё, что нужно, чтобы продолжить работу в любой момент
(и человеку, и Claude в новом чате — достаточно приложить этот файл).

## Цель

Заполнять данные щита **один раз в Excel** (шина → автомат → аппараты → модуль/канал →
клемма → кабель → линия), а однолинейную схему **вместе с нижней таблицей** строить в
AutoCAD одной командой `SXDRAW` из **ваших блоков** (чертёж `02_Однолинейка.dwg`).

Пилотный объект: Сколково Парк, щит ЩР.

## Как пользоваться

1. Заполнить лист **«Однолинейка»** в Excel (белые столбцы — ввод, серые — считаются сами).
2. AutoCAD: `APPLOAD` → `SX_Schema.lsp` (в командной строке: `[SX_Schema v3.5]`).
3. `SXDRAW` → в окне: файл Excel, лист, щит, «Указать точку» (левый нижний угол таблицы),
   библиотека блоков `02_Однолинейка.dwg` → OK.
4. `SXUPDATE` — перестроить схему **без окна**: берёт файл, лист, щит, точку и библиотеку,
   запомненные в этом чертеже при последнем SXDRAW. Порядок: поправили Excel → переключились
   в AutoCAD → `SXUPDATE` (сохранять Excel не обязательно — читается открытая книга).
5. `SXCLEAR` — удалить построенное (всё на слоях `SX_*`). `SXBLOCKS` — пересоздать служебные блоки.

не вставлять столбцы, не вырезать данные.

## Как устроена программа (SX_Schema.lsp)

- Читает Excel напрямую через COM (книга открывается только для чтения), диапазон `A3:BL1000`.
- Места: шаг 20 мм, 17 мест на лист A3. Уровни по высоте сняты с вашего чертежа
  (вставка автомата 217.24, шина L 216.05 / N 211.05, вторая шина 205.22, гребёнка 162.96,
  каналы 139.26, клеммы 137.22, таблица 0–105).
- Ваши блоки: `QF1` (Видимость1 = QF/QFD, Расстояние1 — дотяжка до шины), `Шина`
  (длина под лист), `XT`, `БП`, `Драйвер`, `MK-5-1`, `Розетка1`, лампа
  `$RECOVER_230831092053-0`, `Сервопривод-1`, `EK.1`, `Привод`, `_Боковик_схема Юником`.
  Нет блока в чертеже → копируется из библиотеки DWG; нет и там → простой заменитель `SX_*`.
- Этапы: таблица → листы и шины → группы (автоматы, аппараты, гребёнка, N) → модули → строки
  (каналы, клеммы, PE, УГО).
- Ошибка в одном месте не обрывает построение: всё пишется в `SX_log.txt`
  (этап, № места, данные строки).

### Технические правила (важно при доработке)

- В коде все строки-литералы только латиницей; русские имена — кодами через `sx:ru`
  (работает и при LISPSYS 0, и при 1).
- AutoCAD не различает регистр имён: `sx:N` и `sx:n` — одно и то же. Никаких переменных,
  отличающихся от функций только регистром (на этом была ошибка v3.3).
- `nth` по пустому списку при LISPSYS=1 даёт `consp nil` — использовать `sx:nth0`.
- DCL сохранять в Windows-1251.

- Лист **«Каталог»** — всё оборудование: категория, производитель, модель, префикс/каналы модуля,
  наименование, артикул, полюса, номинал, 30 мА, ширина в модулях DIN. Пополняется строками вниз (до 500).
  Справа настройки: производитель автоматов / аппаратов / модулей (фильтрует выпадающие списки),
  модели клемм. Имя `Модули_спр` теперь указывает на Каталог!C:F.
- Выпадающие списки на «Однолинейке»: E (автомат), F, I–K (аппараты), L (модуль), N, Y.
- Столбец **AE «Статус»** (светофор): нет фазы, нет мощности, дубль клеммы, ошибки W/X,
  5 жил на 1 фазе, розетка без 30 мА, потери > 4 %. Итоги — «Справочник_схемы» J15:K16.
- Защита листа «Однолинейка» паролем **sx** (Рецензирование → Снять защиту листа).
  Открыты для ввода: D, E, F, I, J, K, L, N, P, Y.
- Лист **«Бирки»**: `QF1/XT1` + бирка кабеля (= линия) — для печати.
- «Спецификация» P:R — наименование, артикул, производитель из Каталога; строки 62–63 — клеммы.
