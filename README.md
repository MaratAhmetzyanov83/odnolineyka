# Однолинейка — щит из Excel в AutoCAD

> **Работа на двух ПК (дом / работа):** перед началом — `Получить.cmd`, после работы — `Отправить.cmd`. Что где и что дальше — `СОСТОЯНИЕ.md`.

Данные щита заполняются один раз в Excel. Из них AutoCAD рисует однолинейную схему,
а Excel считает нагрузки, ТКЗ, кабельный журнал и спецификацию.

## Установка один раз

1. **AutoCAD:** `APPLOAD` → `2_AutoCAD/Однолинейка/SX_Schema.lsp` (лучше в «Автозагрузку»). Папку `2_AutoCAD/Однолинейка`
   добавить в «Параметры → Файлы → Путь доступа к вспомогательным файлам», чтобы находился `.dcl`.
   После переезда файлов один раз запустить `SXDRAW` (не `SXUPDATE`) и заново указать книгу и библиотеку блоков.
2. **Excel:** подключить надстройку `3_Макросы_Excel/Однолинейка.xlam` — `4_Инструкции/Надстройка_на_ленте.md`.
   Книги остаются `.xlsx` (внешние ссылки ГРЩ ↔ щиты не ломаются).

## Правила книги

Не добавлять строки и столбцы, не трогать синие ячейки, не вырезать (Ctrl+X).
Файлы одного объекта держать в одной папке — ссылки между ними относительные.
