# Однолинейки — актуальная версия v3.11

| Файл | Что это |
|---|---|
| `Однолинейка_шаблон.xlsx` | Пустой шаблон щита — начинать новый щит отсюда |
| `Однолинейка_пример_ЖК-Остров.xlsx` | Заполненный пример |
| `Видеогайд_Однолинейка_v3.11.mp4` | Видеогайд по работе с таблицей (3 мин, субтитры) |
| `Объект ЖД/` | ГРЩ‑ЖД + 16 щитов, связанных с ГРЩ внешними ссылками |

**Правила:** не добавлять строки и столбцы, не трогать синие ячейки, не вырезать (Ctrl+X).

**Связи ГРЩ ↔ щиты** работают, только если все файлы объекта лежат в одной папке (ссылки относительные). Скачивайте папку `Объект ЖД` целиком.

Что считается и по каким нормам, история версий и найденные замечания — в `chats/2026-09-29_demand-factor-ks/README.md`.
