# Компоновка аппаратов из Excel — CPDRAW

LISP вставляет ваши блоки модульных аппаратов, клемм XT и кросс-модулей. С v2.0 — ещё DIN-рейки, корпус DKC, фазы под гребёнчатые шины и расчёт монтажных проводов. Источник — «Однолинейка» и «Каталог» книги Excel; в книгу пишется только лист «Сборка_щита».

## Установка и запуск

1. Держите `SX_Panel.lsp` и `SX_Panel.dcl` вместе в `2_AutoCAD/Компоновка`. Эту папку можно добавить в AutoCAD: Параметры → Файлы → Путь доступа к вспомогательным файлам. Если папки нет в путях поиска, при первом запуске выберите `SX_Panel.dcl` по запросу программы; путь запоминается.
2. `APPLOAD` → `SX_Panel.lsp`. После замены файла загрузите его повторно; в командной строке должна появиться версия `SX_Panel v2.0`.
3. `CPDRAW` → выберите Excel и щит. Рядов: 0 — авто (программа считает сама), число — не меньше стольких. Библиотека из соседней папки `Блоки` подставляется автоматически после определения пути к DCL. При необходимости укажите библиотеку `База блоков компоновки (1).dwg`. Рабочая база — на Google Диске: `G:\Мой диск\Однолинейка_базы\SX_Компоновка_пользовательские.dwg`; если рядом в `2_AutoCAD/Блоки` её нет, CPDRAW берёт её оттуда.
4. Назначьте блок каждому типу аппарата и клеммам. Для однофазного дифавтомата (2P) по умолчанию предлагается `DA_1PN_36`. Предложенные блоки автоматов соответствуют числу полюсов; конкретную серию проверьте в этом окне. Для динамического блока можно выбрать исполнение. Масштаб и угол задаются здесь же.
5. Для отдельных объектов снимите флажок «Создавать единым блоком». Укажите точку вставки. Аппараты и клеммы останутся своими блоками; подписи будут отдельным текстом. При установленном флажке получится один общий блок.

## Обновление

| Команда | Действие |
|---|---|
| `CPDRAW` | Создать компоновку |
| `CPUPDATE` | Выбрать компоновку и перечитать Excel, сохранив точку, поворот и масштаб |
| `CPEDIT` | Изменить щит, расположение и привязки к блокам |
| `CPDELETE` | Удалить выбранную компоновку |
| `CPEXPLODE` | Разделить готовую компоновку на отдельные объекты |

Габариты измеряются по выбранным блокам. Аппараты располагаются слева направо; клеммы — отдельным нижним рядом. Если аппарат шире рейки, программа предлагает исправить параметры до отрисовки. Рядов добавляется сколько нужно. Атрибуты `IN_A`, `CURVE` и `POLES` автоматов заполняются по Excel.

## Отдельные объекты

В `CPDRAW` снимите флажок «Создавать единым блоком». Выбор сохраняется для следующего запуска. Для уже созданного общего блока выполните `CPEXPLODE` и выберите компоновку. Команда сохраняет вложенные блоки аппаратов, их атрибуты и отдельные подписи.

`CPUPDATE`, `CPEDIT` и `CPDELETE` работают в обоих режимах. Для отдельных объектов выберите любой исходный аппарат или подпись этой компоновки. Через `CPEDIT` можно снова включить общий блок. `CPDELETE` удаляет только объекты выбранной компоновки.

Обновление строит компоновку заново по Excel и настройкам; ручные изменения отдельных элементов при этом заменяются. Для переноса, поворота или масштабирования всей компоновки выбирайте все её объекты, включая заголовок. Заголовок служит опорой при обновлении; если он удалён, используется следующий сохранившийся элемент.

Отдельно скопированные элементы остаются самостоятельными объектами. Они не управляют исходной компоновкой через команды CP. Для второй компоновки с автоматическим обновлением используйте `CPDRAW`.

## Расстояние между DIN-рейками

В окне `CPDRAW` задайте «Межосевое расстояние DIN-реек, мм». По умолчанию — 150 мм. Значение задаёт точный шаг между осями соседних рядов аппаратов и клемм. Высота выбранных блоков этот шаг не изменяет. Укажите положительное число; дробную часть можно отделить точкой или запятой.

Для готовой компоновки используйте `CPEDIT`. Настройка сохраняется в блоке и применяется при `CPUPDATE`. Для старых компоновок без этой настройки `CPUPDATE` сохраняет прежний расчёт шага; при `CPEDIT` появляется новое поле.

## Размер подписей

В окне `CPDRAW` задайте «Высота подписей аппаратов, мм» и «Высота подписей клемм, мм». По умолчанию — 4 мм и 2 мм. Поля принимают положительные числа с точкой или запятой. Для готовой компоновки измените размеры через `CPEDIT`; при `CPUPDATE` они сохраняются.

Размеры относятся к обозначениям над аппаратами (QF, XRM и другим) и вертикальным подписям XT. Значения заданы для компоновки в масштабе 1:1; при масштабировании всего блока текст масштабируется вместе с ним. Внутренние атрибуты библиотечных блоков используют свои размеры.

## Кросс-модуль

Как задано пользователем, учитываются все автоматы выбранного щита, включая вводной. По столбцу V считаются подключения L1/L2/L3; трёхполюсный автомат занимает подключение каждой фазы, двух- и четырёхполюсный также учитывают N. На каждом полюсе оставляется одно подключение под питание. Если фаза не задана, программа предусматривает подключение на каждой фазе и выводит примечание.

Из вашей базы выбирается `EKF_CM_4x7`, `EKF_CM_4x11` или `EKF_CM_4x15`; при превышении вместимости добавляются дополнительные модули. Это расчёт количества подключений для компоновки. Номинальный ток и допустимые сечения кросс-модуля программа не подбирает. Соединительные провода не рисуются.

Для примера «ЩР-1»: 19 автоматов, 19 клеммных групп (23 блока клемм: 18 трёхуровневых и 5 одиночных) и один `EKF_CM_4x11`. Подключения L1/L2/L3: 8/6/7, плюс питание на каждый полюс.

## Клеммы под сечение

Сечение читается из кабеля в столбце Q, например `5х2,5`. Для трёхфазных линий из вашей базы берутся одиночные `VPR-1.5`, `VPR-2.5`, `VPR-4`, `VPR-6`, `VPR-10` или `VPR-16` ближайшего достаточного сечения. Трёхфазная группа: 3 серые GY + 1 синяя BU + 1 PE (зелёно-жёлтая из вашей базы), подряд без разделения между рядами.

Трёхжильный кабель с сечением до 2,5 мм² включительно: один блок `VPR-2.5-3L-GY`; заглушка — `D-VPR-2.5-3L`. Число жил и сечение читаются из столбца Q. Например, `3х1,5` и `3х2,5` используют трёхуровневую клемму. Для `3х4` используются три одиночные клеммы `VPR-4-GY`, `VPR-4-BU` и `VPR-4-PE-YG`; заглушка — `D-VPR-4`. Для остальных линий сохраняется подбор одиночных клемм по сечению и фазам.

Клеммы и заглушки стоят вплотную, без зазоров между группами. На переходах между размерами или типами выбранных клемм и в конце ряда вставляются соответствующие `D-VPR` из вашей базы. Если сечение отсутствует или больше доступного в базе, программа сообщает об этом.

Одноимённые определения блоков, уже имеющиеся в рабочем DWG, сохраняются. Остальные копируются из указанной библиотеки. Компоновка использует слои `CP_*` и работает независимо от `SX_Schema.lsp`.

## Сборка щита (v2.0)

Блок «Сборка щита» в окне `CPDRAW`. Для новых компоновок всё включено; старые при `CPUPDATE` работают как раньше, включить — через `CPEDIT`.

**Порядок на рейках.** Ввод (строка с кодом «Ввод» или линия «Ввод.N», аппарат QS) — первым. Затем кросс-модуль фаз, модуль N/PE, автоматы 3P и 4P, дифавтоматы и 2P (класс 1P+N), автоматы 1P, остальное (МК, контакторы, модули).

**Фазы и гребёнки** (флажок «Фазы L1-L2-L3 и гребёнки, провода»). Фаза — из «Однолинейки», столбец V. Аппараты 1P и 1P+N ставятся по кругу L1-L2-L3. Подряд стоящие аппараты одного класса с фазами по кругу — один отрезок гребёнки PIN (красная полоса и подпись «PIN 1P+N, 18 мод.» под рядом). Фаза у подписи аппарата: «QFD1 L1». Если фаза не задана, она принимается по кругу, у подписи ставится «?», внизу — примечание. Если одной фазы больше, круг рвётся: начинается новый отрезок со своим питанием. Аппарат, ширина которого не равна числу полюсов (например, 4P дифавтомат 7,5 мод.), гребёнкой не питается — проводом.

**Кросс-модули.** Фазный `EKF_CM_4x…` считается по питанию: одно подключение на фазу каждого отрезка гребёнки, N — для гребёнок 1P+N и 4P, плюс аппараты без гребёнки. Модуль N/PE `EKF_CM_2x…` (флажок «Кросс-модуль N и PE»): ряд N — нули автоматов 1P, ряд PE — PE клемм; что не вместилось — на шину PE (в спецификацию).

**Плотная раскладка.** Если аппарат не входит в остаток рейки, туда ставится следующий подходящий. При гребёнках — только аппараты без гребёнки, чтобы не рвать круг фаз.

**Провода.** Кросс-модуль → гребёнка (ток — сумма номиналов фазы, не больше 63 А) или аппарат; ввод → кросс-модуль; аппарат → его МК/контактор → клеммы L, N, PE. N автомата 1P и PE — от модуля N/PE. Сечение — по номиналу аппарата, длина — по чертежу (по горизонтали + по вертикали) + запас на подключение, итог + запас длины, округление до метра. Цвета по умолчанию: L1 белый, L2 черный, L3 красный, N синий, PE Ж/З.

**Корпус и рейки** (флажок «Рисовать DIN-рейки и корпус»). База — `SX_Корпуса.csv` рядом с LISP (DKC ST, STE, CQE N, RAM Base, FRAME; правится в Excel, сохранять «CSV UTF-8»). Поле «Корпус»: пусто — подбор самого маленького по площади из серии (по умолчанию ST), иначе — любой серии; артикул — этот корпус; «-» — без корпуса. Рисуется контур корпуса, DIN-рейки, вертикальные короба (и горизонтальные, если между рейками хватает места).

**Excel, лист «Сборка_щита»** (флажок «Записать в Excel»). Настройки: B4:B12 — цвета, марка провода, запасы; D5:E16 — сечение по току аппарата. Итог для спецификации — A21:G (вид, наименование, модель, кол-во); перечень проводов для сборщика — J21:Q (откуда, куда, проводник, цвет, сечение, длина). Строки щита перезаписываются при каждом `CPDRAW` / `CPUPDATE`. Если книга открыта у вас — пишется в открытую книгу, сохраните её сами.

**«Каталог».** Столбец N для разделов «Провод», «Шины», «Корпус» берёт количество с «Сборка_щита» по наименованию (столбец G). Строки ищутся так: провод — по сечению в модели (C) и цвету в наименовании (G); гребёнка — «Шины» с полюсами (I) 1P / 1P+N / 3P / 4P, в L — модулей в шине; заглушка — I = «заглушка»; шина PE — I = «PE», в L — подключений; кросс-модуль — «4x11» в модели или наименовании; корпус — артикул в C. Чего нет — в итоге помечено «нет — добавьте строку». Столбец Q «Блок компоновки (CPDRAW)» — блок вида спереди для модели: главнее подбора (например, для МК и модулей).

Старую книгу обновить: `py 5_Проверка/patch_assembly.py <книга.xlsx>` (книга закрыта). Прежние ручные числа «Провод» / «Шины» / «Корпус» в столбце O уберите — иначе удвоятся.
