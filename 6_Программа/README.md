# Программа «Объект» — весь объект в одном окне

Цель — уйти от связки «много книг Excel + чертежи». Программа читает книги v3.12, показывает объект целиком
и правит ячейки ввода (запись через Excel, с резервом и журналом). Дальше — расчёт в Python.

## Запуск

1. Двойной щелчок `Объект.cmd`. Выбрать папку объекта (книги щитов). Папка запоминается.
2. Откроется браузер: слева дерево щитов, справа — щит или весь объект.
3. Изменили книги в Excel и **сохранили** — кнопка «Обновить» (читаются только изменённые книги).

Нужно: Python 3.10+, `py -m pip install openpyxl pywin32` (pywin32 — переход к ячейке в Excel и запись правок).

## Что видно

- **Дерево щитов** — кто от кого питается (по «Сеть_щита» G6). Цвет: красный — ошибки, жёлтый — внимание.
- **Весь объект → Замечания** — все ошибки всех щитов одним списком. Фильтры: «Ошибки», «Связи щитов», поиск.
  Щелчок по строке — переход к щиту и линии. Ссылка «Где править» — книга открывается в Excel на этой ячейке.
- **Весь объект → Щиты** — таблица щитов: питание, Руст, Рр, Iр, фидер, ΔU, Iкз, число ошибок.
- **Щит → Линии** — все линии: место, QF, автомат, кабель, L, ΔU Σ, Iкз/In, категория, статус.

## Таблицы — как в Excel

| Что | Как |
|---|---|
| Сортировка | щелчок по заголовку (ещё раз — обратно, третий — снять) |
| Автофильтр | ▾ в заголовке: галочки значений, для чисел — условие (>, <, между…) |
| Выделение | щелчок, Shift — диапазон, Ctrl — добавить, протянуть мышью; Ctrl+A — всё |
| Итоги выделенного | внизу: число ячеек, Σ, среднее, min, max |
| Итоговая строка | внизу таблицы: Σ / max / min по столбцу — по тому, что видно после фильтра |
| Копировать / вставить | Ctrl+C — в Excel, Word; Ctrl+V — столбец значений из Excel в правимые ячейки |
| Закрепление | первые столбцы (Место, QF, Линия) не уезжают при прокрутке вправо |
| Столбцы | кнопка «Столбцы»: показать / скрыть / порядок; ширина — тянуть край заголовка. Запоминается |
| Группировка | «Группировать»: по фазе, QF, автомату, кабелю… с итогами; щелчок по группе — свернуть |
| Полосы | «Загр., %» (Iр / In) и «ΔUΣ» (доля от допустимой): зелёный → жёлтый (80 %) → красный (100 %) |
| Клавиши | стрелки, Ctrl+стрелки, PgUp / PgDn, Home / End, Tab; Ctrl+F — поиск |
| В Excel | выгрузить то, что видно (фильтр, сортировка, столбцы) |
| «Все линии» | вкладка объекта: линии всех щитов в одной таблице |

## Правка (запись в книги)

Правимые столбцы — со значком ✎: наименование, P, Lпл, марка, жил, Sмин, In ручной, ∥, автомат («авто» или текст —
только в первой строке группы), шина; у щита — «Питание вручную». Расчётные (Iр, In, S, ΔU, Iкз) — не правятся.

- Ввод: начать печатать или F2 / двойной щелчок; Enter — вниз, Tab — вправо, Esc — отмена; список вариантов — в ячейке.
- Ctrl+Enter — значение во все выделенные; Ctrl+D — заполнить вниз; Ctrl+V — вставить; Del — очистить.
- Правки копятся (жёлтые ячейки, «Правок: N» вверху). **Ctrl+S / «Записать в книги»** — запись.
- Ctrl+Z — отменить последнюю несохранённую правку; если их нет — отменить последнюю запись в книгу.
- Запись: книга не должна быть открыта в Excel (иначе — сообщение). Своя скрытая копия Excel вписывает значения
  в ячейки ввода, пересчитывает, сохраняет; окно перечитывает книгу — новые Iр, ΔU, Iкз и замечания видны сразу.
- Перед записью — копия книги в `<папка объекта>\_окно\резерв\<время>\`. Журнал — кнопка «Журнал»
  (`_окно\журнал.jsonl`: кто, когда, ячейка, было → стало).
- Книга изменилась после чтения (правили в Excel) — запись не делается: «Обновить» и повторить.

## Проверки

- **Из книг** — то, что уже проверил Excel: статус строки «Однолинейки» (AE), категория, питающая линия.
- **Связи щитов** (новое, по всему объекту):
  - вышестоящий считает по старой нагрузке нижестоящего (Руст в «Сеть_щита» раздел Б ≠ Руст щита);
  - нижестоящий знает старый фидер (In, длина ≠ линия у вышестоящего);
  - фидер мал: In < Iр щита;
  - селективность: In фидера < 1,6 × наибольший отходящий автомат нижестоящего;
  - фидер «Щит» без книги щита в папке; вышестоящая книга не найдена; линия-фидер у двух щитов;
  - щит без питания.

## Важно

- Значения — на момент **последнего сохранения** в Excel. Книги меняются только кнопкой «Записать в книги».
- Папки `_…`, `Архив…`, `Резерв…` не читаются (там копии).
- Кэш чтения — `6_Программа/кэш/` (не в Git).
