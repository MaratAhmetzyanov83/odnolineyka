# Программа «Объект» — весь объект в одном окне

Цель — уйти от связки «много книг Excel + чертежи». Сначала программа **только читает** книги v3.12
и показывает объект целиком. Потом — правка из окна, потом расчёт в Python.

## Запуск

1. Двойной щелчок `Объект.cmd`. Выбрать папку объекта (книги щитов). Папка запоминается.
2. Откроется браузер: слева дерево щитов, справа — щит или весь объект.
3. Изменили книги в Excel и **сохранили** — кнопка «Обновить» (читаются только изменённые книги).

Нужно: Python 3.10+, `py -m pip install openpyxl pywin32` (pywin32 — для перехода к ячейке в Excel).

## Что видно

- **Дерево щитов** — кто от кого питается (по «Сеть_щита» G6). Цвет: красный — ошибки, жёлтый — внимание.
- **Весь объект → Замечания** — все ошибки всех щитов одним списком. Фильтры: «Ошибки», «Связи щитов», поиск.
  Щелчок по строке — переход к щиту и линии. Ссылка «Где править» — книга открывается в Excel на этой ячейке.
- **Весь объект → Щиты** — таблица щитов: питание, Руст, Рр, Iр, фидер, ΔU, Iкз, число ошибок.
- **Щит → Линии** — все линии: место, QF, автомат, кабель, L, ΔU Σ, Iкз/In, категория, статус.

## Проверки

- **Из книг** — то, что уже проверил Excel: статус строки «Однолинейки» (AE), категория, питающая линия.
- **Связи щитов** (новое, по всему объекту):
  - вышестоящий считает по старой нагрузке нижестоящего (Руст в «Сеть_щита» раздел Б ≠ Руст щита);
  - нижестоящий знает старый фидер (In, длина ≠ линия у вышестоящего);
  - фидер мал: In < Iр щита;
  - селективность: In фидера < 1,6 × наибольший отходящий автомат нижестоящего;
  - фидер «Щит» без книги щита в папке; вышестоящая книга не найдена; линия-фидер у двух щитов;
  - щит без питания.

## Важно

- Книги только читаются. Значения — на момент **последнего сохранения** в Excel.
- Папки `_…`, `Архив…`, `Резерв…` не читаются (там копии).
- Кэш чтения — `6_Программа/кэш/` (не в Git).
