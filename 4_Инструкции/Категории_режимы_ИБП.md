# Категории надёжности, режимы и ИБП (v3.12)

Памятка проектировщика: что вводить, что считается само, как читать листы «Режимы» и «ИБП».
Правила книги прежние: строки и столбцы не вставлять, синие ячейки не трогать. Новые поля стоят в свободных столбцах и на новых листах. Модель внедряет скрипт `_Разработка/2026-09-29_speedup-automation/scripts/model_v312.py` (повторный запуск безопасен: введённое вами не затирается).

## 1. Что вводить

| Что | Где | Как |
|---|---|---|
| **Требуемая категория линии** | «Исходные данные», столбец **BN** | список: `I особая`, `I`, `II`, `III`. Пусто = III. Пресета по коду нет: одни и те же розетки бывают разной категории |
| **Шина линии** | «Однолинейка», столбец **D** «Шина» (как раньше) | имя шины пишется в строке с автоматом (E = «авто»); линии группы ниже входят в ту же шину. Пусто = основная шина. Линия «Исходных данных» связана со строкой «Однолинейки» по номеру линии: «Исходные данные» D = «Однолинейка» R |
| **Секция линии** | «Исходные данные», столбец **BB** | 1 / 2 / 3, пусто = 1 (список теперь допускает 3). Для обычной шины секция даёт тип «Ввод 1 / 2 / 3» |
| **Тип шины вручную** | «Питание_щита», раздел 6, таблица «Шины щита» **B73:D82** | шина (имя как в «Однолинейке» D; основная шина — `основная`), щит (пусто = любой), тип: `Ввод 1`, `Ввод 2`, `Ввод 3`, `ИБП`, `ДГУ`, `Одиночная`. Если шина есть в таблице, тип берётся оттуда |
| **Схема щита** | «Питание_щита», раздел 6, **C65:E67** (столбцы = щиты 1–3, как в разделе 3) | число вводов (1 / 2 / 3); АВР (да / нет); «ИБП / ЩГП питается от» (Ввод 1 / 2 / 3) |
| **Пожарная — переопределение** | «Исходные данные», столбец **BO** | `да` / `нет`. Пусто = по коду потребителя («Справочная» BD) |
| Пресет «пожарная» по коду | «Справочная» **BD4:BD51** (строки те же, что у кодов P4:P51 и группы Кс AZ) | формула: категория ПЗ «Системы противопожарной защиты», либо в названии кода дымоудаление / противодым / подпор / огнезадерживающий / пожарный насос, либо код СПЗ… / ПНС…; иначе «нет». Поверх формулы можно записать `да` / `нет` |
| Настройки ИБП | лист «ИБП», жёлтые ячейки | допустимая загрузка, cos φ на выходе, автономия, U АКБ, КПД, коэффициент разряда, заряд АКБ, cos φ входа, ряд типоразмеров |

Для линии-фидера нижестоящего щита (группа «Щит») категория и пожарная задаются так же в её строке «Исходных данных»: в ГРЩ линия ЩСПЗ-ЖД.1 помечается `да` в BO вручную (её код в «Справочной» не описан).

## 2. Что считается само

Обеспеченная категория линии зависит от типа её шины и схемы щита:

| Тип шины | Обеспечивает |
|---|---|
| Ввод 1 / 2 / 3, один ввод в схеме щита | III |
| Ввод 1 / 2 / 3, 2 и более вводов, АВР нет | II |
| Ввод 1 / 2 / 3, 2 и более вводов, АВР да | I |
| ИБП, ДГУ | I особая |
| Одиночная | III (источник для режимов — ввод по секции BB) |

Если требуемая категория выше обеспеченной, линия помечается **НЕ ОБЕСПЕЧЕНА**. Это подсказка: схема и остальные расчёты от неё не меняются.

Тип шины без таблицы: имя содержит «ИБП» — ИБП, «ДГУ» — ДГУ, иначе «Ввод N» по секции BB.

Новые расчётные столбцы «Исходных данных»: **BP** категория (итог), **BQ** пожарная (итог), **BR** шина, **BS** тип шины, **BT** источник для режимов (Ввод 1/2/3, ИБП, ДГУ), **BU** «Категория обеспечена», **BV** «ОК / НЕ ОБЕСПЕЧЕНА» (красным одним правилом на BN3:BV1000), **BW:CA** служебные (номер нарушения, строка «Однолинейки», шина группы, щит, тип по таблице). Итог по книге: «Справочная» BE16:BF16 и лист «Режимы» C8.

## 3. Лист «Режимы» (после «Нагрузка_щитов»)

Вверху: щит (выбор в C3, пусто = первый), схема щита, итог «Не обеспечено: N линий» (B8:D8, красный при N > 0).

Расчёт по правилам «Нагрузка_щитов»:
- Рр набора линий = Руст быт × Кс быт (по таблице, по сумме Руст быт **этого набора**) + Ко × Σ(Pсил × Кс) + Σ Pпост. Поэтому «Ввод 1» в нормальном режиме совпадает с «Секцией 1» листа «Нагрузка_щитов», а «Итого» без пожарных и ИБП совпадает с «Весь щит» (блок сверки внизу).
- Qр = Рр × tg φ (cos φ набора как в «Нагрузка_щитов» V8), Sр = √(Р² + Q²), Iр = Sр / (√3 × Uн), Uн из «Справочной» BQ29. Iр по перекосу фаз остаётся в «Нагрузка_щитов» V7.

**1. Режимы × источники** (столбцы Ввод 1, Ввод 2, Ввод 3, ИБП, ДГУ, Итого; строки Руст, Кс, cos φ, tg φ, Pр, Qр, Sр, Iр как в таблице ИОС1, ниже серым слагаемые):

| Блок (строки) | Режим и как считается |
|---|---|
| 1) 13–26 | **Нормальный** (СВ отключён): каждая шина на своём источнике, пожарные линии не входят. Нагрузка ИБП учтена один раз: **вход ИБП** (лист «ИБП») добавлен к тому вводу, от которого питается ЩГП. Столбец «ИБП» — нагрузка на выходе (справочно), в «Итого» не входит |
| 2) 28–41, 3) 43–56 | **Аварийный**: потерян Ввод 1 (вся нагрузка Вводов 1+2 и вход ИБП на Вводе 2) / потерян Ввод 2 (на Вводе 1). Ввод 3, ИБП, ДГУ без изменений |
| 4) 58–63 | **Максимум аварийного** по каждому столбцу (больший Sр из двух вариантов) и какой ввод потерян |
| 5) 65–78 | **Потеряны все вводы**: работают только шины ИБП и ДГУ (без пожарных линий) |
| 6) 80–93 | **Пожар**: пожарные нагрузки отдельным блоком, **не участвуют в расчёте максимума** (п. 6.9 СП 31-110-2003) |
| 7) 95–99 | «Нормальный + пожарные» (арифметическая сумма P и Q блоков 1 и 6), для проверки вводов при пожаре |

**2. По категориям** (101–108; для ТУ и ПЗ, без привязки к секциям): I особая / I / II / III, число линий, Pуст, Pр, Qр, Sр без пожарных, отдельно пожарные Pуст и Pр, число необеспеченных. Кс быт применяется к каждому набору отдельно, поэтому сумма строк может отличаться от «Итого».

**3. Необеспеченные линии** (110–132): счётчик по всей книге и перечень первых 20 (линия — наименование, щит, требуется, обеспечена, шина, тип шины).

**4. Сверка с «Нагрузка_щитов»** (134–142): Руст и Рр весь щит, секции 1 и 2; Iр по фазе и симметричный (разница — перекос фаз).

Ниже (строка 144 и далее) — служебные суммы по источникам и категориям для трёх щитов; их не править.

## 4. Лист «ИБП»

Работает, если у выбранного на «Режимах» щита есть шина типа ИБП (C5 = «есть»); иначе вход ИБП = 0.

| Раздел | Что | Адрес |
|---|---|---|
| 1 | Нагрузка шины ИБП: P расчётная (без пожарных, из «Режимов»), **добавка вручную** (например, пожарные линии на ИБП), cos φ, S | C9:C13, ввод C10 |
| 2 | Допустимая загрузка (0,75) → требуемая S; cos φ на выходе (0,9) → требуемая S по кВт; ближайший типоразмер по кВА и по кВт, принятый; загрузка и проверка | ввод C16, C18; результат C17:C26 |
| 3 | АКБ: автономия, мин (15); U АКБ, В (240); КПД инвертора (0,95); коэффициент разряда/старения (0,8). Ёмкость, А·ч = P, кВт × 1000 × t, мин / 60 / (U, В × КПД × k) | ввод C29:C32, результат C33:C35 |
| 4 | Вход ИБП: P вх = P / КПД × (1 + заряд АКБ, 10 %); cos φ входа (0,95); S вх, I вх. **C46 — нагрузка на ЩГП, идёт в «Режимы»** | ввод C38:C39, результат C40:C46 |
| 5 | Ряд типоразмеров, кВА: 6, 10, 15, 20, 30, 40, 60, 80, 100, 120, 160, 200 (можно править, порядок любой) | C50:C61 |

Двойного счёта нет: в нормальном режиме на ввод ложится **вход** ИБП (P вх), а выход ИБП показан в столбце «ИБП» справочно и в «Итого» не входит. Если ИБП питает и пожарные линии, впишите их мощность в «Добавку» (C10): они попадут в подбор ИБП и в вход.

## 5. Пример: 2 ввода, СВ нормально отключён, ЩГП с ИБП

«Питание_щита»: C65 = 2 (вводов), C66 = да (АВР на СВ), C67 = Ввод 1 (ЩГП питается от Ввода 1). Линии (группа «Пост», Кс = 1, cos φ 0,95): 100 кВт на секции 1, 80 кВт на секции 2 (BB = 2), 10 кВт на шине «ИБП» (в «Однолинейке» D = ИБП). ИБП: КПД 0,95, заряд 10 %.

Проверено на копии примера в Excel:
- Типы шин: основная (секция 1) = Ввод 1, секция 2 = Ввод 2, «ИБП» = ИБП. Обеспечено: Ввод 1 и 2 — I (2 ввода + АВР), ИБП — I особая.
- Вход ИБП = 10 / 0,95 × 1,1 = 11,58 кВт.
- Нормальный: Ввод 1 = 100 + 11,58 = **111,58** кВт, Ввод 2 = **80**, ИБП (выход) 10 — в итог не входит; Итого **191,58** кВт.
- Потерян Ввод 1: Ввод 2 = 191,58 кВт (Sр 201,66 кВА, Iр 291,1 А). Потерян Ввод 2: Ввод 1 = 191,58. Максимум 191,58 кВт: на этот режим проверяются вводы, аппараты и кабели.
- Потеряны все вводы: ИБП 10 кВт (Sр 10,53 кВА), ДГУ 0.
- Линия с категорией «I особая» на основной шине: НЕ ОБЕСПЕЧЕНА (нужна шина ИБП или ДГУ). Линия «I» на основной шине: ОК (2 ввода + АВР).

ГРЩ-ЖД (копия, секции 1 и 2): Руст 524,27 кВт (262,37 / 261,90), Рр весь щит 275,80 кВт (секции 159,28 / 123,46), Iр по фазе 427,5 А (симметричный 419,0 А). Если пометить ЩСПЗ-ЖД.1 пожарной: нормальный 274,20 кВт, пожар 1,60 кВт, нормальный + пожарные 275,80.

## 6. Сборка в ГРЩ: нижестоящие щиты (`grsh_rollup.py`)

Внедрена для объекта ЖД (ГРЩ‑ЖД + 16 щитов). Шаг идёт после `model_v312.py`: `py grsh_rollup.py --folder "<папка объекта>"` (флаг `--model` сначала применит `model_v312.py`). Повторный запуск безопасен.

**Что отдаёт нижний щит** («Питание_щита», раздел 4, строки 45–47 = щиты 1–3):

| Где | Что |
|---|---|
| J44:S47 | итоги для проектировщика: Руст и Рр по категориям, Руст и Рр пожарных (как раньше, по собственным Кс щита) |
| T44:BD47 | 37 **составляющих**, из которых вышестоящий щит сам считает Рр: для I особая / I / II / III и для пожарных по 5 значений (Руст, Руст быт, Рр сил = Σ P·Кс, Руст пост, Σ P·cos φ); те же 5 для «на вводах» (без шин ИБП/ДГУ; обычные и пожарные); вход ИБП (P и P·cos φ, только для щита, выбранного на «Режимы» C3) |

**Что берёт ГРЩ** («Нижестоящие_щиты»): U:BE — «Вставить связь» с T45:BD45 файла нижестоящего щита, тот же механизм и те же файлы, что D:J (столбцы Руст…Iр). P:T — служебные (щит, источник, категория и пожарная линии‑фидера, признак сборки). BF:BG — проверка «категория линии‑фидера не ниже высшей категории нагрузки щита». Если у линии‑фидера нет данных v3.12 (нижний щит старой версии, нет связи), она считается как раньше: одной категорией «Исходных данных» BN.

**Как считается (логика и обоснование).** Категория и пожарность линии на нижний щит берутся **по составу нижнего щита**, а не одной категорией на всю линию, и **не долями**. Доли Руст или Рр нельзя переносить наверх: Кс быт (таблица по сумме Руст быт) и Ко нелинейны, поэтому Рр набора не равен сумме Рр частей. Составляющие аддитивны: ГРЩ складывает их по категориям со своими линиями и заново применяет Кс быт и Ко к объединённому набору (так же, как «Режимы» считает один щит).

- **Двойного счёта нет.** Строка «Исходных данных» с нижним щитом (группа «Щит») при наличии данных сборки исключается из собственных сумм («Нагрузка_щитов» BB = 1 для этой линии); вместо неё идут составляющие нижнего щита. Итог совпадает со старым: Руст 524,27 кВт, Рр 275,80 кВт.
- **Категория линии‑фидера** (BN) остаётся для проверки обеспеченности (BU/BV). Если фидер записан ниже категории нагрузки щита, в «Нижестоящие_щиты» BG будет «фидер III ниже нагрузки I».
- **Пожарные** нижнего щита идут в блок «Пожар» ГРЩ и в столбцы «Пожарные» таблицы по категориям, в максимум не входят. Пожарные нижнего щита в «Категориях» ГРЩ записываются в категорию линии‑фидера. Если линия‑фидер помечена пожарной (BO = да), вся нагрузка щита считается пожарной.
- **ИБП.** Нагрузка на шинах ИБП/ДГУ нижнего щита на линию‑фидер не ложится (питается от его ИБП/ДГУ); вместо неё в нагрузку линии‑фидера (источник этой линии в ГРЩ) добавляется **вход ИБП** нижнего щита (P вх с листа «ИБП» и его cos φ входа). В таблицу по категориям вход ИБП не входит (там нагрузка на выходе, как и на «Режимах» одного щита); он показан отдельным столбцом.
- **Секция линии‑фидера** (BB «Исходных данных») определяет её источник (Ввод 1/2/3), как у любой линии.

**Где смотреть ответ на вопрос «сколько кВт какой категории на объекте».** Лист «Категории_по_щитам» (после «ИБП»), блок 1: I особая / I / II / III (Руст, Рр, Sр), пожарные вне максимума (Руст, Рр), вход ИБП. Те же цифры на «Режимы», раздел 2 (строки 103–107). Блок 2 — Руст по щитам (строка = щит, столбцы = категории, пожарные, вход ИБП) с контрольной суммой; блок 3 — Рр по щитам (справочно: у каждого щита свой Кс быт и Ко, сумма строк не равна Рр ГРЩ).

Пока категории не заполнены (BN пусто), вся нагрузка — III: I особая, I, II = 0; III = 524,27 кВт (Рр 275,80 кВт), пожарные = 0.

**Как подключить новый нижестоящий щит:** 1) в щите применить `model_v312.py` и `grsh_rollup.py` (экспорт T44:BD47); 2) в ГРЩ на «Нижестоящие_щиты» в строке фидера выполнить «Вставить связь» для D:J (C45:I45), как раньше, и для U:BE (T45:BD45); или запустить `grsh_rollup.py` на ГРЩ — он сам добавит U:BE в строки, где уже есть связь D:J.

**Внешние связи.** Скрипт приводит пути связей к файлам в той же папке (Excel сохраняет их относительными). В книгах v3.11 адреса были записаны в виде «%D0%9E…», который Excel не расшифровывает: связь была «битой», работал только кэш значений. Теперь «Данные → Изменить связи» показывает файлы в одной папке.

**Ограничения.**
- Вход ИБП нижнего щита считается только для щита, выбранного на его «Режимы» (C3; у остальных щитов книги 0).
- Многоуровневая сборка (щит под щитом) работает по тем же формулам, но ИБП/ДГУ‑шины второго уровня проверены только на расчётном примере, не на реальных данных.
- Пожарные нагрузки нижнего щита относятся в таблице по категориям к категории линии‑фидера, а не к категориям линий самого щита (общая сумма пожарных верна).
- «Линий, шт.» на «Режимы» считает линию‑фидер по её категории BN; нагрузка распределена по составу.
- Значения из файлов нижестоящих щитов приходят после «Обновить связи»; без обновления работает кэш последнего сохранения.

## 8. Допущения и ограничения

- Кс быт считается по сумме Руст быт набора линий (источник, категория), как в «Секция 1 / 2» листа «Нагрузка_щитов». Сумма Pр по источникам поэтому может быть больше «Итого» (разные Кс быт).
- Шина ДГУ в нормальном режиме считается на своём источнике (условие «каждая шина на своём источнике»). Если ДГУ в норме питается от ввода, отнесите эти линии к шине соответствующей секции.
- Аварийный режим рассматривает потерю Ввода 1 или Ввода 2 (СВ включён). Ввод 3 остаётся независимым источником.
- Секция 3 («Исходные данные» BB = 3) учитывается на «Режимах» (Ввод 3). «Нагрузка_щитов» AJ теперь различает секции 1, 2 и 3: блоки AG:AH (секции 1 и 2) секцию 3 не включают (раньше относили к секции 1), в «Весь щит» (AF) она входит. Результаты секций 1 и 2 без линий секции 3 не изменились. «Расчёт_нагрузок» в режимах «секция 1 / 2» также не включает секцию 3.
- Пожарные линии на шине ИБП в мощность ИБП не входят (учтите в «Добавке» C10).
- Iр на «Режимах» симметричный (от Sр); по наиболее нагруженной фазе — «Нагрузка_щитов» V7.
- Скрытые листы: макрос `SX_Spec.bas` находит «Спецификация_авто» по имени в цикле по `Worksheets`, Select/Activate не использует (только возвращает прежний активный лист), скрытый черновик ему не мешает. LISP находит лист «Однолинейка» по метке SX_DATA в BC1 и сканирует все листы, в том числе скрытые.
