# Компоновка щита (вид спереди): SXLAYOUT

Программа: `2_AutoCAD/Компоновка/SX_Layout.lsp` + `SX_Layout.dcl` (держать вместе). Работает в паре с `SX_Schema.lsp`:
данные берёт из той же книги Excel, что и однолинейка, и рисует вид щита спереди в масштабе 1:1 (мм) на блоках
из вашей базы компоновки.

## Установка один раз

1. `APPLOAD` → `2_AutoCAD/Компоновка/SX_Layout.lsp` (лучше в «Автозагрузку», после `SX_Schema.lsp`).
2. Папку `2_AutoCAD/Компоновка` добавить в «Параметры → Файлы → Путь доступа к вспомогательным файлам» (там же,
   где `2_AutoCAD/Однолинейка`), чтобы находились `.dcl` и `SX_Schema.lsp`. Если `SX_Schema.lsp` не загружен,
   SXLAYOUT загрузит его сам из соседней папки `2_AutoCAD/Однолинейка` (по пути к базе блоков или к `.dcl`),
   а если не найдёт — спросит файл. Указывать нужно именно `SX_Schema.lsp`, не `SX_Layout.lsp`.

## Команды

| Команда | Что делает |
|---|---|
| `SXLAYOUT` | окно: книга Excel, щит, ограничения по месту (Ш/В/Г не более, установка, серия), корпус DKC (подобрать или выбрать), запас по рейкам, «каждый тип с новой рейки», база блоков, точка (левый верхний угол корпуса) |
| `SXLUPDATE` | перестроить с параметрами, запомненными в чертеже (после правки книги) |
| `SXLCLEAR` | удалить компоновку (всё на слоях `SXL_*`); однолинейку (`SX_*`) не трогает |

## Что рисуется и откуда берётся

| На компоновке | Откуда |
|---|---|
| Автоматы и дифавтоматы, обозначения QF/QFD | «Однолинейка»: G (обозначение), H (текст «2P С16А 30мА»), по нему строка «Каталога» (столбец U) |
| Аппараты после автомата (МК, КМ, БП, трансформатор) | «Однолинейка»: I-K; КМ → KM1.., трансформатор → TV1.., БП → G1.. |
| Модули (KNX и др.) | «Однолинейка»: AH (обозначение), AI (модель) |
| Клеммы XT | «Однолинейка»: P; на строку BW трёхуровневых и BX доп. проходных (модели из «Каталога», настройки S7, S8), по номеру XT |
| Ручные позиции: клеммы ввода, шины N/PE, вводной автомат… | «Каталог», столбец O «Вручную / запас» (разделы Автомат, Дифавтомат, Аппарат, Модуль, Клемма, Шины). Торцевые изоляторы `D-*`, перемычки `SBF*`, упоры `UK-E*` не рисуются |
| Немодульное оборудование (на монтажной панели) | «Каталог», столбец O, если в столбце Q указан блок, а раздел не из списка выше (например «Прочее»). Ставится под последней занятой рейкой |
| Корпус, рейки, кабель-каналы, размеры, заголовок, заполнение реек | считается программой |
| Перечень справа: обозначения (QFD1-QFD28), наименование, количество | по нарисованным позициям |

Порядок на рейках — по типам: клеммы → шины → модули → автоматы (многополюсные первыми) → дифавтоматы → аппараты.
Рейки заполняются по рядам: ряд 1 всех секций, потом ряд 2 и т.д. Позиция не разрывается между рейками
(длинный ряд клемм режется на куски по длине рейки).

## Блоки

Блок для позиции ищется так (берётся первый найденный в чертеже или в базе):

1. имя из столбца **Q «Каталога»** у этой модели (если заполнено);
2. правило по типу: автомат 1P/2P/3P/4P → `S201`/`S202`/`S203`/`S204`, дифавтомат 2P → `DS201`, 3P/4P → `DS203`, МК → `MR-5-1`;
3. **имя блока = модель** из столбца C «Каталога» (например `VPR-2.5-3L-GY`);
4. модель + `_ATT_DEF` и похожее имя для модулей (`ZIOMB24V2` → `ZIO-MB24_ATT_DEF`).

Нет блока → прямоугольник шириной «Ширина, мод. DIN» (L «Каталога») × 18 мм с названием модели.
Блок ставится по габаритам: левый край вплотную к предыдущему аппарату, середина по высоте на ось рейки, поэтому
точка вставки в блоке может быть любой. Ширина берётся из блока, а не из «Каталога».
Рейка — ваш динамический блок `Дин.рейка` (длина задаётся свойством `Расстояние1`).

Чтобы добавить новый аппарат в базу: начертите вид спереди 1:1 и назовите блок как модель в «Каталоге»
(или впишите имя блока в столбец Q).

## Корпус

Корпуса берутся из базы **`2_AutoCAD/Компоновка/SX_Корпуса.csv`** (лежит рядом с программой). Сейчас там 222 корпуса
DKC, собранные с dkc.ru 04.10.2026:

| Серия | Тип | Установка | Размеры |
|---|---|---|---|
| ST, STE — корпус с монтажной платой | PLATE | навесной | 58 + 58 типоразмеров, 200×300×150 … 1400×1000×300, 1200×1200×300 |
| CQE N — собранный напольный корпус | CAB | напольный | 86 типоразмеров, 1400…2200 × 400…1600 × 400…800 |
| RAM Base ЩРн-п IP65 | MOD | навесной | 4…72 модуля |
| FRAME ЩРн-п / ЩРв-п | MOD | навесной / встраиваемый | 2…36 модулей |

Из вариантов одного размера в базу взят основной артикул: сплошная дверь у ST/STE (артикул с прозрачной дверью указан
в «Примечании»), белый щиток с тонированной дверцей у FRAME. Размеры: ВxШxГ, мм.

**Ограничения по месту** (в окне, раздел «Корпус»):
- ширина, высота, глубина «не более», мм (пусто — без ограничения);
- установка: любая / навесной / встраиваемый / напольный;
- серия: все / ST / STE / CQE N / RAM Base / FRAME.

Список «Корпус» сразу показывает только подходящие корпуса и их число. Можно выбрать конкретный или оставить
«Подобрать автоматически». Подбор берёт **самый маленький по площади** подходящий корпус, куда всё помещается
с запасом (по умолчанию 20 % длины каждой рейки), и в нём по возможности начинает каждый тип с новой рейки.
Если с запасом не помещается ни в один корпус, укладывает без запаса и пишет замечание. Если не помещается вообще,
лишние позиции рисуются **красным под корпусом** с надписью «НЕ ПОМЕСТИЛОСЬ В КОРПУС». Если под ограничения не
подходит ни один корпус, программа так и говорит: ослабьте ограничения.

Ограничения и выбранный корпус запоминаются в чертеже (для `SXLUPDATE`), артикул корпуса попадает в заголовок
и первой строкой в перечень.

**Как раскладываются рейки:**
- MOD (модульный щиток): ряды × модули по паспорту, рейки по центру;
- PLATE (ST/STE): на монтажной плате рейки с шагом 150 мм, между ними кабель-каналы 40 мм, поле от края 40 мм;
  у малых корпусов (высота до 400 мм) — 125 / 25 / 25;
- CAB (CQE N): шаг 205 мм, канал 60 мм, поле 30 мм (как в эталоне 02_Однолинейка); при ширине от 1200 мм — две секции.

Эти числа — столбцы «Шаг реек», «Короб», «Поле», «Секций» в CSV; их можно менять для любого корпуса.

**Править базу:** открыть `SX_Корпуса.csv` в Excel, добавить или изменить строку, сохранить как «CSV UTF-8
(разделитель — точка с запятой)». Строки, начинающиеся с `#`, — комментарии. Пересобрать базу с сайта заново:
`_Разработка/2026-10-03_panel-layout/src/make_encl_csv.py` (данные в `data/*.json`).

## Замечания программы

Выводятся в командную строку и в `SXL_log.txt` (рядом с `SX_Schema.lsp`). Например:
- автомат не найден в «Каталоге» по столбцу U → ширина по числу полюсов;
- нет блока и нет ширины (L) → принято 4 модуля;
- блок из столбца Q не найден ни в чертеже, ни в базе;
- запас не выдержан / не поместилось.
