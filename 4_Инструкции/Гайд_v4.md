# ГАЙД ПО ОДНОЛИНЕЙКЕ v4

Одна книга — один объект: все щиты, все линии, все расчёты. Связей между файлами нет. Текст написан по правилам ASD-STE100: одно действие в предложении, один термин — одно значение.

Разделы 4–15 — порядок работы. На листах «Объект», «Щиты», «Шины» есть свой короткий гайд. Как и по каким нормам всё считается — лист «Методика».

## 1. ТЕРМИНЫ

| Термин | Значение |
|---|---|
| Объект | Здание или комплекс. Одна книга = один объект. |
| Щит | Электрический щит объекта. Каждый щит — одна строка на листе «Щиты». |
| ВРУ (корневой щит) | Щит без вышестоящего щита в книге: ГРЩ, ВРУ. Для него вводятся данные сети. |
| Линия | Отходящая цепь щита. Одна строка на листе «Линии» = одно место схемы. |
| Номер линии | Текст вида «Код.Помещение.№». Пример: R.1.05.4. Код ищется на листе «Коды». |
| Место | Колонка на схеме (шаг 20 мм). На листе A3 — 17 мест (настройка «Таблицы_норм» BF4). |
| Вводной узел | Первые места схемы щита (обычно 1–15): вводы, АВР, байпас. Вы рисуете их сами. Строки узла в схеме не рисуются. |
| Фидер | Линия, которая питает другой щит этой книги. Номер линии = имя щита — фидер найден автоматически. |
| Группа | Несколько линий на одном автомате. Автомат стоит в первой строке группы. |
| Дифзащита | Ток утечки защиты (УЗО, дифавтомат): 10, 30, 100, 300 мА. Пусто — по коду. |
| Жёлтый столбец | Ввод. Вводите данные только сюда. |
| Серый столбец | Расчёт. Значение считается само. Служебные столбцы свёрнуты кнопкой «+» над таблицей. |

## 2. ПРАВИЛА КНИГИ

> **ОСТОРОЖНО:** Не сортируйте таблицу «Линии». Порядок строк = порядок мест и групп на схеме.

> **ОСТОРОЖНО:** Не переименовывайте листы, таблицы и заголовки столбцов. Формулы и программы AutoCAD ищут их по имени.

> **ОСТОРОЖНО:** Не вводите данные в серые столбцы и на лист «Однолинейка». Лист «Однолинейка» считается сам.

> **ВНИМАНИЕ:** Новую строку добавляйте внутри таблицы: правая кнопка на строке → «Вставить» → «Строки таблицы выше». Формулы продлятся сами.

> **ВНИМАНИЕ:** Перед массовой правкой сохраните копию книги. После макросов Ctrl+Z не работает.

## 4. ПОРЯДОК РАБОТЫ (КРАТКО)

1. Заполните лист «Объект» (раздел 5).  _(Объект!C3)_
2. Внесите щиты на лист «Щиты» (раздел 6).  _(Щиты!A10)_
3. Проверьте коды потребителей на листе «Коды» (раздел 7).  _(Коды!A4)_
4. Заполните линии на листе «Линии» (раздел 8).  _(Линии!A3)_
5. Если нужно, задайте тип шины на листе «Шины» (раздел 9).  _(Шины!A9)_
6. Откройте лист «Проверка» и устраните замечания (раздел 10).  _(Проверка!A1)_
7. Возьмите результаты: «Итоги_щитов», «Режимы», «Расчёт_нагрузок», журнал, бирки (разделы 11–13).
8. Нарисуйте схему в AutoCAD и выпустите спецификацию (разделы 14–15).

## 5. ЛИСТ «ОБЪЕКТ»

5.1. C3 — введите название и адрес объекта.  _(Объект!C3)_
5.2. C8 — методика. Для нового проекта оставьте «нормы 2026».  _(Объект!C8)_
5.3. C9 — kп.к. Для частного дома оставьте 1.  _(Объект!C9)_
> **ПРИМЕЧАНИЕ:** Что значит каждая настройка и на что влияет — гайд внизу листа «Объект».

## 6. ЛИСТ «ЩИТЫ»

6.1. Щит — введите имя щита. Каждый щит — одна строка.  _(Щиты!A10)_
6.2. Вводов, АВР, ИБП от — введите схему щита.  _(Щиты!C10)_
6.3. Мест под вводной узел — сколько первых мест схемы занимает вводной узел (обычно 15).
6.4. «Питается от» оставьте пусто. Книга найдёт фидер сама. Заполняйте, только если фидера нет в «Линиях».
6.5. Для ВРУ / ГРЩ введите данные сети: Iкз min и Iкз max от сетевой организации или «ТП» и Sтр.
> **ОСТОРОЖНО:** Без данных сети книга не считает ток КЗ и не проверяет отключение 0,4 с ни в одном щите.

## 7. ЛИСТ «КОДЫ»

7.1. Найдите код в таблице «Коды» (столбец A).  _(Коды!A4)_
7.2. Чтобы добавить код, введите его в первую пустую строку под таблицей. Таблица расширится сама.
7.3. В таблице «УГО» задайте значок, дифзащиту (мА, «да» = 30), минимальный автомат, клеммы 3L.  _(Коды!O4)_
> **ВНИМАНИЕ:** Один код = одно определение на весь объект. Если изменить опуск кода, изменятся длины всех его линий.

## 8. ЛИСТ «ЛИНИИ»

Строка = одно место схемы. Щиты разделены линией и цветом. Строки вводного узла подсвечены голубым.

8.1. Щит — введите щит. Места одного щита ставьте подряд.  _(Линии!A3)_
8.2. № места — оставьте пусто: место будет следующим по порядку, после вводного узла. Число — своё место (пропуск = пустая колонка). «-» — строки нет на схеме.  _(Линии!B3)_
8.3. «Лист / место» показывает лист схемы A3 и место на нём. «узел» — строка вводного узла.  _(Линии!C3)_
8.4. Номер линии — введите номер. Наименование подставится по коду. Чтобы переписать — введите свой текст в «Наименование».  _(Линии!D3)_
8.5. Питает щит — заполняйте, только если номер фидера не совпадает с именем щита.
8.6. Мощность, кол-во, фазы, напряжение, группа Кс, длины, кабель — введите или оставьте пусто (по коду, по чертежу).
8.7. Категория надёжности и «Пожарная» — для линий, которым они нужны.
8.8. Схема: «Автомат» = «авто» в первой строке группы. Дифзащита, аппараты, модуль, канал, клемма — как в v3.12.  _(Линии!AC3)_
8.9. Режим: «вручную» — строка только в таблице; «рисовать» — нарисовать строку вводного узла.

| Что нужно | Что ввести |
|---|---|
| Линия со своим автоматом | Автомат = «авто». Клемма пусто (номер по порядку) или своя. |
| Несколько линий на одном автомате | Первая строка: «авто». Следующие строки: автомат пусто. |
| Дифзащита 30 / 100 / 300 мА | Дифзащита = 30 (100, 300). «нет» — без неё. |
| Вторая шина (ИБП, секция) | Шина = имя шины в строке с автоматом. |
| Линия на модуле | Модуль = модель в первой строке модуля. «-» — в первой строке после модуля. Канал: пусто — авто, № — вручную. |
| Параллельная линия, резерв, тот же кабель, без клеммы | Канал = «=», «р», «+», «б/к». |
| Клемма без номера | Клемма = «нет». |
> **ПРИМЕЧАНИЕ:** Справа серые столбцы: «Замечания», ток, автомат, сечение, ΔU, Iкз, категория. Примечание к заголовку — формула и норма.

## 9. ЛИСТ «ШИНЫ»

9.1. Обычно лист пустой: имя шины с «ИБП» или «ДГУ» определяется само, иначе — по секции линии.
9.2. Заполните строку, только если имя шины не говорит о типе (пример: шина «ЩГП» от ИБП).  _(Шины!A9)_

## 10. ЛИСТ «ПРОВЕРКА»

10.1. Слева — замечания по щитам. Справа — по линиям. «→» — перейти к строке.  _(Проверка!A4)_

| Замечание | Что сделать |
|---|---|
| нет данных сети для ТКЗ | Введите Iкз от сетевой организации или трансформатор в строке ВРУ на листе «Щиты». |
| ПЕРЕГРУЗ | Ток группы больше номинала. Увеличьте автомат или разделите группу. |
| КАБЕЛЬ НЕ ЗАЩИЩЁН | Автомат больше допустимого тока кабеля. Увеличьте сечение или уменьшите автомат. |
| категория … не обеспечена | Нужен второй ввод с АВР у щита или шина ИБП/ДГУ. Или снизьте требуемую категорию. |
| розетка без дифзащиты до 30 мА | Поставьте дифзащиту 30 мА (или 10 мА) на розеточную группу (ПУЭ 7.1.79). |
| Icu … < Iкз max | Выберите автомат с большей отключающей способностью. |
| потери … > … | Увеличьте сечение или сократите длину. |
| не на схеме | Уберите «-» из № места или удалите строку. |

## 11. ЛИСТЫ «ИТОГИ_ЩИТОВ» И «РЕЖИМЫ»

11.1. «Итоги_щитов» C3 — выберите щит. Карточка B4:D27 — данные под однолинейку (Руст, Кс, Рр, cos φ, Iр, фазы).  _(Итоги_щитов!C3)_
11.2. Справа на «Итогах_щитов» — все щиты объекта одной таблицей.
11.3. «Режимы» C3 — выберите щит. Смотрите нормальный, аварийный, пожар; блок 7 — кВт по категориям для ТУ; блок 8 — ИБП.  _(Режимы!C3)_
> **ПРИМЕЧАНИЕ:** Пожарные нагрузки не входят в расчётный максимум (СП 256 п. 7.1.9).

## 12. ЛИСТ «РАСЧЁТ_НАГРУЗОК» (ДЛЯ ПОЯСНИТЕЛЬНОЙ ЗАПИСКИ)

12.1. C3 — объект. C4 — щит. C5 — режим: весь щит или секция.  _(Расчёт_нагрузок!C4)_
12.2. Скопируйте таблицу и основные показатели в пояснительную записку как значения.

## 13. ЖУРНАЛ И БИРКИ

13.1. «Кабельный_журнал»: маркировка, трасса, кабель по проекту. «Проложено», испытания, дата — заполняют на монтаже.  _(Кабельный_журнал!A2)_
13.2. P2 — запас длины для сводки по маркам кабеля (0,2 = 20 %).  _(Кабельный_журнал!P2)_
13.3. Для AutoCAD запустите макрос «Выгрузить журнал». В Data Link укажите этот лёгкий файл.
13.4. «Бирки»: строка на каждый провод — от автомата к устройству, от устройства к клемме, от клеммы — кабель.  _(Бирки!A3)_

## 14. СХЕМА В AUTOCAD

14.1. Выполните SXDRAW. Выберите эту книгу, лист «Однолинейка», щит. Один щит — один чертёж.
14.2. После правки книги выполните SXUPDATE. Компоновка щита — SXLAYOUT.
14.3. Вводной узел нарисуйте сами. Строку узла можно нарисовать: Режим = «рисовать».

## 15. СПЕЦИФИКАЦИЯ

15.1. «Спецификация» D1 — выберите щит или «все».  _(Спецификация!D1)_
15.2. Проверьте «Каталог»: N — по схеме выбранного щита, O — запас вручную.  _(Каталог!A1)_
15.3. Нажмите «Обновить спецификацию» (макрос SX_Spec). Источник — лист «Спецификация_авто».  _(Спецификация_авто!A1)_
> **ОСТОРОЖНО:** «Обновить спецификацию» стирает «Спецификация» B4:J160. Ручные правки делайте в «Каталоге».

## 16. ГДЕ ПОДРОБНЕЕ

Лист «Методика» и документ 4_Инструкции/Методика_расчёта.md — формулы, нормы, проверка по нормам РФ. Пример со всеми случаями — «Однолинейка_v4_пример_все_случаи.xlsx».
