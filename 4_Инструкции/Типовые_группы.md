# Макрос «Типовые группы» (SX_Groups.bas)

Файл: `3_Макросы_Excel/SX_Groups.bas` (модуль `SX_Groups`, две макрокоманды).

- `SX_InsertGroup` заполняет выделенные строки листа «Однолинейка» выбранным шаблоном.
- `SX_SaveAsGroup` сохраняет значения ввода выделенной строки как новый шаблон.

## Установка в PERSONAL.XLSB

1. Если личной книги макросов нет: Вид → Макросы → Запись макроса → «Сохранить в: Личная книга макросов» → OK → сразу «Остановить запись». Закройте Excel и на вопрос о сохранении PERSONAL.XLSB ответьте «Да».
2. Alt+F11 → в дереве выберите VBAProject (PERSONAL.XLSB) → File → Import File → `SX_Groups.bas`.
3. Сохраните PERSONAL.XLSB (Ctrl+S в VBE). Настройки безопасности и Trust Center менять не нужно.

Файл целиком в ASCII. Русский текст закодирован и собирается при запуске функцией `U()`, поэтому импорт работает при любой кодовой странице. Тексты сообщений правьте по коду с осторожностью, а шаблоны и заголовки таблицы удобнее менять на листе.

## Кнопки на панели быстрого доступа

Файл → Параметры → Панель быстрого доступа → «Выбрать команды из: Макросы» → `PERSONAL.XLSB!SX_InsertGroup` → Добавить. Так же добавьте `SX_SaveAsGroup`. Кнопкой «Изменить» задайте значок и подпись.

## Как пользоваться

1. Откройте книгу щита (xlsx) и перейдите на лист «Однолинейка».
2. Выделите одну или несколько строк. Подойдёт любая ячейка строки. Учитываются строки 3–1000, скрытые строки пропускаются.
3. Запустите `SX_InsertGroup` и введите номер шаблона (или часть названия) в окне.
4. Если в целевых ячейках уже что-то есть, один раз спросят «Перезаписать?». «Да» перезаписывает, «Нет» заполняет только пустые ячейки, «Отмена» выходит.
5. В конце будет сообщение «Заполнено N строк шаблоном X» со списком пропусков.

**Отмена (Ctrl+Z) после макроса не работает.** Перед массовым заполнением сохраните копию книги.

При первом запуске в книге создаётся лист «Типовые_группы» со стартовыми шаблонами (последний лист книги).

### Куда пишет шаблон

Номер линии строки берётся из столбца R «Однолинейки» (это Разбивка_по_щитам!H). В «Однолинейке» кабель, наименование, мощность и фаза считаются формулами, поэтому их вводят на другом листе.

| Лист | Столбцы, которые заполняет шаблон |
|---|---|
| Однолинейка (та же строка) | D шина, E автомат, F 30 мА, I–K аппараты, L модуль, N канал, Y режим |
| Исходные данные (строка с тем же номером линии в столбце D) | F напряжение, H фазы, N марка кабеля, O жилы, Q сечение, R автомат вручную, S потолок/пол, AZ группа Кс, BA Кс, BB секция, BD категория ПЗ, BH К прокладки |

Другие столбцы макрос не трогает. Мощность и количество потребителей (E, G), длины, ручное наименование (C), номер линии (D, синяя ячейка) и клеммы (P) у каждой линии свои, поэтому в шаблоны не входят. Ручная фаза вводится на листе «Нагрузка_щитов», столбец E. Это балансировка нагрузки по линиям, в шаблон она не входит.

### Что макрос никогда не делает

- Не пишет в ячейки с формулой. Пропуски считаются и показываются в итоговом сообщении.
- Не пишет в синие (RGB 157,195,230) и объединённые ячейки.
- Не пишет значения, не проходящие выпадающие списки и проверки: такие ячейки возвращаются как были.
- Не добавляет строки и столбцы на листы проекта.

**Важно про формулы по умолчанию.** В «Исходных данных» строки 21–78 содержат формулы по умолчанию в столбцах F, H, N, O, Q. Шаблон в такие ячейки не запишет. Чтобы применить значения шаблона, очистите нужную ячейку (Delete) и запустите макрос снова. Либо оставьте формулу, если она вас устраивает.

Защита листов снимается паролем `sx` и возвращается с теми же параметрами. При любой ошибке защита и настройки Excel (пересчёт, обновление экрана, события) восстанавливаются.

### Режимы шаблона

- **каждая строка** (по умолчанию): все значения пишутся в каждую выделенную строку.
- **одна группа**: шина, автомат, 30 мА, аппараты и модуль пишутся только в первую выделенную строку (как в примере «Остров»: автомат и модуль стоят в первой строке группы). Канал, режим и столбцы «Исходных данных» пишутся в каждую строку.

## Как пополнять шаблоны

**Способ 1: из готовой строки.** Выделите настроенную строку «Однолинейки» → `SX_SaveAsGroup` → введите имя. Значения ввода этой строки (без формул) добавятся новой строкой на лист «Типовые_группы». Режим по умолчанию «каждая строка», при необходимости измените его на «одна группа».

**Способ 2: вручную.** На листе «Типовые_группы» добавьте строку внизу (с 4-й строки):

- столбец A содержит имя, B описание, C режим;
- значения вводите в столбцах справа под нужными заголовками, пустая ячейка означает «не трогать»;
- строка 2 (серая) служебная: «лист!столбец». Её менять не нужно. Столбцы с именем, которого нет в списке ввода, макрос игнорирует и сообщает об этом.

Значения вводите как в основной таблице: аппараты и модули должны быть в «Каталоге» этой книги, категория ПЗ в списке «Категории_ПЗ», марка кабеля в «Справочной». На листе шаблонов есть выпадающие списки-подсказки (только предупреждение).

## Стартовые шаблоны

Выведены из примера «Остров», книг ЖД и Сколково (v3.2).

1. Розетки 1ф (R)
2. Розетка 3ф 400 В (5 жил)
3. Свет 1ф 3х1,5 (L)
4. Свет + МК-5-1, 5х1,5 (группа)
5. Свет на модуле ZIOMB24V2 (группа)
6. Кондиционер (K)
7. Вентиляция (В, П, ПВ)
8. Насос (НВК)
9. Обогрев кровли и водостоков (OV)
10. Ввод / не рисовать (вручную)
11. Привод / кран
12. Датчик протечки (WD)

Шаблоны 11 и 12 сделаны по справочнику: в книгах линий мало. Значения «Сил/0,5», автомат 10 или 16 А взяты из практики книг ЖД. Проверьте их под свой объект.
