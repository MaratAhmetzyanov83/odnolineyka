# ГАЙД ПО ОДНОЛИНЕЙКЕ v5 (бета)

Одна книга — один объект: все щиты, все линии, все расчёты. После DLN строка почти готова: таблица сама подбирает наименование, мощность, автомат, сечение, фазу и клемму. Вы проверяете и правите только то, что нужно.

> **ОСТОРОЖНО:** Включите макросы (кнопка «Включить содержимое» при открытии). Без макросов книга считает правильно, но серые значения не возвращаются после стирания, а после вставки строк нужно нажать «Починить формулы».

## 1. ГЛАВНОЕ ПРАВИЛО: СЕРОЕ И СИНЕЕ

| Что видите | Что это значит |
|---|---|
| Серый курсив | Значение выбрала таблица (по коду, по расчёту, по чертежу). Его можно не трогать. |
| Синий жирный | Значение вписали вы. Таблица его не меняет и проверяет. |
| Стёрли синее | Вернулось серое (выбор таблицы). |
| Жёлтая шапка | Столбец для ввода. Курсив в шапке — в столбце есть серые значения. |
| Серая шапка | Результат. Вводить не нужно. |
| Красная ячейка «Замечания» | В строке есть ошибка. Текст говорит, что исправить. |

## 2. ЛИСТЫ КНИГИ

| Лист | Что на нём |
|---|---|
| Объект | Ввод. Название, методика расчёта, как собирать наименования, марки кабелей. |
| Щиты | Ввод. Строка на щит: вводы, АВР, ИБП, место под вводной узел. Справа — таблица «Шины» (обычно пустая). |
| Линии | Ввод. Все линии всех щитов. Кнопки щитов показывают один щит. |
| Коды | Ввод. Типовые потребители (коды и УГО одной таблицей), этажи, кабели, экспликация. Стандарт отдела — правьте под объект. |
| Проверка | Результат. Все замечания книги. |
| Щит | Результат. Выбранный щит: таблица под схемой и итоги по каждому вводу. |
| Кабельный_журнал, Спецификация | Результат. По выбранному щиту или по всему объекту (выбор вверху листа). |
| Бирки | Результат. Строка на провод — для сборки щита. |
| Изменения | Результат. Что изменилось после «Зафиксировать выдачу»: было → стало и листы схемы для таблицы изменений. |
| Наклейки | Результат. Лента под аппаратами на A4 (кнопка на листе «Щит»). |
| Гайд, Каталог, Методика, Таблицы_норм | Справка. |
| Режимы, Расчёт_нагрузок | В конце книги, нужны не всегда: режимы вводов (АВР, ИБП, пожар) и таблица нагрузок для пояснительной записки. |

## 3. ПОРЯДОК РАБОТЫ

1. Лист «Объект»: название, методика, как собирать наименования (по номеру помещения или по экспликации).  _(Объект!C3)_
2. Лист «Щиты»: строка на щит. Вводов, АВР, ИБП от, «Мест под вводной узел» (пусто — 17, весь первый лист; 11 — узел на части листа). «Питается от» книга находит сама (серое). Для ВРУ — данные сети.  _(Щиты!A13)_
3. AutoCAD, DLN: номера линий, длины, число потребителей, пометки выносок (Relay, DIM, DALI) приходят в «Линии».
4. Лист «Линии»: проверьте серое. Впишите то, что знаете точно (мощность оборудования, свой автомат). Отметьте группы: «гр».  _(Линии!B3)_
5. Столбец «Замечания» и лист «Проверка»: исправьте ошибки.  _(Проверка!A1)_
6. Лист «Щит»: выберите щит. Проверьте таблицу под схемой и итоги по вводам — они идут на схему.  _(Щит!C3)_
7. SXDRAW рисует схему по скрытому листу «Однолинейка». Вводной узел (места под узел) рисуете сами.
8. Спецификация: корпус и комплект щита впишите в таблицу справа (один раз на щит). Остальное книга считает сама.  _(Спецификация!M2)_
9. Лист «Щит», кнопка «Выгрузить для AutoCAD»: лёгкий файл рядом с книгой для Data Link (схема, итоги, журнал, спецификация по каждому щиту).  _(Щит!L1)_
10. Перед выдачей: «Упорядочить щит» (по желанию) и «Зафиксировать выдачу» (заодно закрепить фазы). После правок — лист «Изменения».  _(Изменения!B4)_

## 4. ЛИСТ «ЛИНИИ»: СТОЛБЦЫ

| Столбец | Что делает таблица / что вводите вы |
|---|---|
| Щит | Имя щита. Строки щита — подряд, в порядке мест на схеме. |
| Номер линии | Код.Этаж.Помещение.Группа (R.1.05.3). Приходит из DLN. Строка с кодом «Ввод» — ввод щита. |
| Наименование | Серое: название кода + помещение. Своё — впишите. |
| Кол-во потребителей | Из DLN. Нужно для мощности и опусков. |
| Р, кВт | Серое: кВт на шт по коду × кол-во (розетки 0,06 кВт). Фидер — Руст нижнего щита. Ввод — нагрузка щита. |
| Группа | Пусто — свой автомат. «гр» — линия на автомате строки выше. «узо» — свой автомат на шине УЗО (выше строка «УЗО.1»). |
| Автомат | Серое: полюса, характеристика, номинал, ток утечки. В строке «гр» — «↑» и автомат группы. Свой: 25, C25 или 2P C25А 30мА. |
| Управление | Серое: по пометке выноски (Relay, DIM, DALI) или коду. По управлению подставляется модуль («Ещё» → «Модуль»). |
| Аппараты | Аппараты после автомата через «;» (КМ, МК, Т, БП 24V 480W — мощность и напряжение БП читаются из названия). |
| Сечение, мм² | Серое: подбор (см. раздел 11). Своё — впишите, таблица проверит. |
| Длина линии (по плану) | Серое: из чертежа (DLN). Итог с опусками — «Длина, м». |
| Фаза | Серое: автобалансировка по автоматам. Своя: 1, 2, 3 или 1,2,3. |
| Клемма | Серое: следующая XT. «нет» — без номера. |
| Замечания, Iр, Длина, ΔU, Кабель, Лист / место | Результаты строки. |

## 5. КНОПКИ ЩИТОВ, КАРТОЧКА И «ЕЩЁ»

Над таблицей — кнопки щитов. Нажмите кнопку — видны только строки этого щита. Слева вверху — карточка щита: откуда питается, Руст, Рр, Iр, cos φ, ΔU до шин, сколько листов схемы, сколько замечаний. Чтобы снова видеть все щиты — нажмите значок «очистить фильтр» на кнопках.

Редкие столбцы свёрнуты в «Ещё» (кнопка «+» над столбцом «Лист / место»): «Питает щит», утечка (мА), фазы, напряжение, группа Кс, Кс, cos φ, секция, шина, категория ввода, пожарная, вид нагрузки, режим строки, модуль, канал, № места, марка, жилы, К прокладки, лоток и гофра, примечание, столбцы DLN. Первые два столбца «Ещё» — результаты: «Ток утечки, мА» и «Lмакс по КЗ, м».

## 6. ЛИСТ «ЩИТ»: ТО, ЧТО ИДЁТ НА СХЕМУ

Выберите щит в ячейке C3. Слева — таблица под схемой: строка на место (шаг 20 мм), лист схемы, обозначение, фаза, Рн, Iн, наименование, кабель, автомат. Справа — итоги по каждому вводу: категория, Руст, Рр, Iр, cos φ, Кс, нагрузка фаз.

| Какие линии в каком вводе | Линии щита — по шине и секции («Шина», «Секция» в «Ещё»). Нижние щиты — по своему фидеру. Шина ИБП — к вводу из «ИБП от» на листе «Щиты». |
| Щит с АВР | Итоги — нормальный режим. В строке «Ввод» — вся нагрузка щита (один ввод тянет всё): по ней подобраны автомат и кабель ввода. |

## 7. ЖУРНАЛ, СПЕЦИФИКАЦИЯ, ВЫГРУЗКА

| Кабельный журнал | Раскладка отдела: линия, откуда — куда, кабель, лоток, гофра «Ø20 L=…», длина. Справа — числа для подсчёта и сводки: кабели с запасом (L1, по умолчанию 20 %) и вверх до 10 м, гофра по диаметрам (вверх до бухты), лоток, сводка ПТО (кабель + потолок / пол → артикул). |
| Спецификация | Раздел 1 — корпус и комплект (вручную, таблица справа) + аппараты по схеме из «Каталога»; чего нет в «Каталоге» — строкой с пометкой «впишите артикул». Раздел 2 — кабели (по марке, от крупных к мелким), гофра, крепёж по нормам расхода (таблица справа). |
| Нормы расхода | Крепёж = база × «на 1 м», вверх до кратности. База — метры гофры (по диаметру, «ПВХ все», «ПНД все») или кабеля после округления. По умолчанию — как в проекте «Жуковка»: клипсы 2 шт/м, гвозди и баллоны — 1 упаковка на 1000 клипс. |
| Выгрузка для AutoCAD | Файл «<книга>_AutoCAD.xlsx» рядом с книгой: на каждый щит листы «<щит> схема», «итоги», «журнал», «спец». Имена постоянные — Data Link в AutoCAD после новой выгрузки только обновите. |

## 8. LED 24 В: ЛИНИИ ПОСЛЕ БЛОКА ПИТАНИЯ

1. Строка автомата: в «Аппаратах» — «МК-5-1; БП 24V 480W»; диммер — в «Модуле» («Ещё»).
2. Ниже — линии 24 В с «гр» в «Группе». Напряжение 24 — по коду или в «Ещё» → «Напряжение».
3. Таблица считает постоянный ток (I = P/U), потери от БП (допустимо 5 %, «Объект» C14) и подбирает сечение; автомат — по стороне 230 В.
4. Проверяет БП: нужно = 1,3 × Σ (Uвых·I) («Объект» C13) — столбцы «БП: нужно, Вт» и «Uвых БП, В» в «Ещё»; ток канала диммера — если в «Каталоге» вписан «Ток канала, А».

## 9. МОДУЛИ, УЗО НА ГРУППУ, ПОРЯДОК, ВЫДАЧА, НАКЛЕЙКИ

| Модули | Серое в «Модуле»: модель по управлению («Объект», таблица «Модули_умолч»: Relay и шторы — ZIOMB24V2, шторы — 2 выхода на линию; DIM — ZDINDX4; DALI — ZDID64X2, линии на одной шине; клапаны — ZCL-8HT230). Подряд идущие линии с одним управлением — на каналы одного модуля, новый — когда каналы кончились. Своя модель — синим, «-» — конец модуля. |
| УЗО на группу | Строка «УЗО.1» (код УЗО, в «Аппаратах» «УЗО 2P 40А 30мА»), ниже линии со своими автоматами и «узо» в «Группе». Автомат строки УЗО — по току блока, линии — обычные автоматы. Проверки: номинал УЗО ≥ автомата перед ним и тока блока, ток утечки блока ≤ 1/3 уставки. Шину УЗО на схеме пока рисуете сами. |
| Упорядочить щит | Кнопка над «Линиями» — для щита активной ячейки: вводной узел на месте, дальше по управлению (Relay, DIM, DALI, шторы, клапаны, без управления), коду и помещению. Группы «гр», блоки УЗО и свои модули не разрываются. |
| Закрепить фазы | Серые фазы щита становятся синими — правки больше не переставят фазы. |
| Зафиксировать выдачу | Снимок с номером изменения (предлагает закрепить фазы). «Изменения»: добавлено / удалено / было → стало по щитам и листы схемы для таблицы изменений; в «Линиях» изменённое — оранжевым, новые линии — зелёным. |
| Наклейки | Лист «Щит», кнопка «Наклейки (A4)» → лист «Наклейки»: ячейка = 1 модуль DIN (18 мм), под каждым аппаратом — обозначение, линия, наименование. Модулей на рейку — C2; рейка длиннее листа — несколькими полосами (над каждой — «Рейка N»). Печать A4, масштаб 100 %: ширина ячейки подгоняется под текущий принтер при нажатии кнопки. |

## 10. КАТЕГОРИИ НАДЁЖНОСТИ — ТОЛЬКО У ВВОДОВ

У линий категории нет. Категория ввода берётся по схеме щита (столбец «Категория шины «Ввод»» на «Щитах»; шины ИБП и ДГУ — I особая). Своя категория — в строке «Ввод», столбец «Категория ввода» в «Ещё». Категория идёт в итоги по вводам на листе «Щит».

## 11. КАК ТАБЛИЦА ПОДБИРАЕТ И ПРОВЕРЯЕТ

| Автомат | Номинал — наименьший из ряда, не меньше тока группы (Iр ≤ 0,9·In) и минимума кода (свет 10 А, розетки 16 А); перед БП — не меньше 10 А. Полюса: 1ф — 1P, 3ф — 3P, с утечкой — 2P / 4P (дифавтомат). Характеристика — по коду (C). |
| Сечение | Наименьшее сечение, не меньше минимума кода, при котором: Iдоп·К ≥ In автомата (ПУЭ 1.3.10); потери от ВРУ не больше 3 % до светильников и 4 % до прочих (СП 256 п. 8.23); Iкз в конце линии отключает автомат за 0,4 с (ПУЭ 1.7.79). |
| Фаза | Автоматы щита от крупных к мелким: каждому — фаза с наименьшей нагрузкой. Линии группы — на фазе своего автомата. Ручная фаза не меняется. Перед выдачей можно вписать фазы вручную, чтобы они не менялись при правках. |
| Ввод щита | Нагрузка щита. Щит с АВР или с одним вводом — вся нагрузка; два ввода без АВР — нагрузка своей секции. |
| Линии 24 В | Постоянный ток: I = P/U, потери 2·ρ·L·I/S от выхода БП, не больше 5 %. Сечение — по току линии и потерям, без проверки Iкз (кабель защищает БП). Жил по умолчанию 2. |
| Ток утечки | ПУЭ 7.1.83: 0,4 мА на 1 А тока + 10 мкА на 1 м линии, у группы — сумма. С дифзащитой — не больше 1/3 уставки (30 мА → 10 мА, 10 мА → 3,3 мА), иначе замечание. |
| Lмакс по КЗ | Наибольшая длина линии, при которой Iкз в конце ещё отключает автомат за 0,4 с. Если «Длина, м» близка к Lмакс — увеличьте сечение. |
| Наименование | Название кода + «, пом. 105» (или «по экспликации» — название помещения). |
> **ПРИМЕЧАНИЕ:** Подробно — лист «Методика».

## 12. ВСТАВКА И УДАЛЕНИЕ СТРОК

Строки вставляйте внутри таблицы (правая кнопка → Вставить → Строки таблицы выше). Макрос сам чинит формулы. Если в «Замечаниях» видно «строки сдвинуты» — нажмите кнопку «Починить формулы» над таблицей.

> **ВНИМАНИЕ:** Не сортируйте таблицу кнопками Excel: порядок строк — это порядок мест на схеме.

## 13. ЧТО ЕЩЁ БУДЕТ

AutoCAD: SXDRAW — с места после вводного узла, шина УЗО вниз-вправо, типовые вводные узлы по «Типу вводного узла», обновление готовой схемы по номеру линии, DLN для v5.
