# Однолинейка 1.08 — как работать

Таблица та же, что 1.05: те же листы, столбцы и порядок заполнения. Новое добавлено справа от старых столбцов, на новых листах в конце книги и на вкладке «Однолинейка» на ленте Excel.
Правила 1.05 остаются: не добавлять строки, не вставлять столбцы, не вырезать (Ctrl+X).
Везде одно правило: **пусто — таблица подставляет сама, своё значение главнее.**

## Порядок работы

1. **Планы → DLN.** В AutoCAD `DLN` заполняет «Исходные данные»: номер линии, длины, гофру ПВХ/ПНД, кол-во потребителей, текст выноски (Relay / DIM / DALI). После правок планов — `DLN_UPD`. Он обновит длины, кол-во и выноски, ваши мощность, кабель и «Потолок/Пол» не тронет. Пропавшие с плана линии подсветит красным.
2. **«Исходные данные».** Мощность, напряжение, фазы — как раньше. Остальное подставится само:
   - **марка и жилы:** пусто — марка по умолчанию; жилы: 1ф — 3, 3ф — 5, 24 В — 2;
   - **автомат:** по току, но не меньше минимального по коду (розетки 16 А, свет 10 А);
   - **сечение:** наибольшее из трёх — по току (ПУЭ 1.3.6), по коду (розетки 2,5), по потерям (≤ 4,5 %, на 24 В ≤ 5 %);
   - **наименование:** как в 1.05 (код + этаж + «Пом. №»). Вариант — по экспликации: «Настройки» → «Наименование по экспликации» = «да», названия помещений — на листе «Экспликация» («Розеточная группа Кухня»);
   - **справа (BB:BH):** дифзащита по коду, ток утечки (ПУЭ 7.1.83), Lмакс по КЗ (если на «Диапазонах» указан Zпетли щита).

   «Сечение (ручное)» и «автомат (ручное)» по-прежнему главнее.
3. **«Разбивка_по_щитам» — как лист «Однолинейка» v3: слева направо = схема сверху вниз.**
   Щит · Начало линии · **Место · Лист · Шина · Группа · Автомат · Дифзащита · QF · Автомат (итог) · Аппараты · Модуль · Модуль (итог) · Модель · Канал · Канал (итог) · Клемма · Клемма (итог) · Рисовать** · Номер линии · Наименование · ток · мощность · фаза · Кабель · Статус.
   Порядок строк = порядок мест на схеме, пустая строка — пустое место (как в 1.05). **Белое — вводите, голубое — считается.** Всё необязательно:

   | Столбец | Пусто | Своё |
   |---|---|---|
   | Шина | основная | имя второй шины (ИБП) |
   | Группа | свой автомат | «гр» — на автомате строки выше; «узо» — на шине УЗО строки выше |
   | Автомат | подбор: «2P C16A 30мА» | как писать на схеме; «-» — без автомата |
   | Дифзащита, мА | по коду | 10 / 30 / 100 / 300 / «нет» |
   | Аппараты | — | до трёх через «;»: «КМ; БП 24V 240W» |
   | Модуль | по пометке выноски и коду | модель из списка; «-» — без модуля |
   | Канал | следующий | число; «=» — тот же канал; «р» — резерв |
   | Клемма | XT по порядку | «нет» или своя |
   | Рисовать | да (вводной узел — нет) | «нет» / «да» |

   Номер линии в такой строке оранжевый — значит, в «Статусе» есть замечание. Границы листов (по 17 мест) и щитов видны чертой, вводной узел — серым. Служебные столбцы 1.05 свёрнуты: плюсик над столбцами их показывает. Щит и «Начало линии» закреплены.
   **Фазы** — автобаланс по нагрузке: новый автомат ставится на наименее загруженную фазу щита, «гр» — на фазу строки выше. Ручная фаза — как раньше, «Нагрузка_щитов» E.
4. **«Диапазоны» H:I (по щиту):** сколько мест занимает вводной узел (пусто = 17, весь первый лист) и Zпетли на шинах из ТКЗ (для Lмакс).
5. **SXDRAW** (AutoCAD) → выбрать таблицу 1.08 и щит. Лист «Однолинейка» скрыт и заполняется сам, его не трогайте. Узел не рисуется, схема начинается после него. `SXUPDATE` — перестроить без окна.
6. **Вкладка «Однолинейка»:**
   - **Обновить спецификацию** — по щиту из «Спецификация» H1 (пусто — все): автоматы, аппараты, модули, клеммы, кабели (+20 %, вверх до 10 м), гофра, клипсы (2 шт/м). Строки с «вручную» в «Примечании» (корпус, шины) сохраняются;
   - **Зафиксировать выдачу** — перед отправкой снабжению или сборщику;
   - **Показать изменения** — что поменялось после выдачи: лист «Изменения» (было → стало, лист схемы) и подсветка ячеек;
   - **Бирки** — строка на каждый провод (QF → аппарат → модуль → XT → кабель);
   - **Наклейки** — лента под аппаратами: клетка = 1 модуль DIN (18 мм). Проверьте пробной печатью.

## Настройки — лист «Настройки» (сразу после «Справочной»)

| Блок | Что там |
|---|---|
| Общие настройки | Uн; допустимые потери до 50 В; коэффициент прокладки; марка по умолчанию; «Пом. №»; мест на лист; клипсы/м; запас кабеля; округление; **наименование по экспликации (да / нет)** |
| Допустимый длительный ток | ПУЭ табл. 1.3.6 — по ней подбирается сечение |
| Коды потребителей | по коду: УГО, дифзащита, мин. автомат, каналов модуля, клемм 3L, мин. сечение |
| УГО → блок AutoCAD | значки для SXDRAW |
| Модули | модель, префикс, каналы, тип, ширина DIN |
| Модель по умолчанию | Relay / Шторы / DIM / DALI / Клапан → модель |

«Справочная» — как в 1.05 (кабели, коды, этажи, ПТО), над каждой таблицей подпись.

## Пока не умеет

- **УЗО на группу («узо»)** — таблица и спецификация учитывают, а на схеме рисуете вручную, в статусе так и написано.
- **Типовые вводные узлы**, **обновление готовой схемы по номеру линии**, **ГРЩ** (категории, режимы, ИБП) — по плану «потом».
- **Ширина модулей DIN для наклеек:** у KNX-модулей не задана, берётся 4 модуля. Впишите в Справочная BF.
