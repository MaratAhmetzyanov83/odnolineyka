# Надстройка «Однолинейка» на ленте Excel

Файл: `3_Макросы_Excel/Однолинейка.xlam`. В самих книгах макросов нет — кнопки работают с активной книгой.

## Подключить (один раз на ПК)

1. Excel → Файл → Параметры → Надстройки.
2. Внизу «Управление: Надстройки Excel» → «Перейти».
3. «Обзор» → выберите `3_Макросы_Excel/Однолинейка.xlam` → OK.
4. На ленте появится вкладка «Однолинейка».

Если Excel пишет, что макросы заблокированы: правой кнопкой по файлу `.xlam` → Свойства → «Разблокировать».

## Кнопки

| Группа | Кнопка | Что делает |
|---|---|---|
| Спецификация | Обновить спецификацию | «Спецификация_авто» → «Спецификация» (значения). Изменения против принятой ревизии подсвечиваются, удалённые — в листе «Изменения». |
| | Принять изменения | Снабжение получило: подсветка снимается, ревизия +1. |
| | Каталог: обновить | Из `1_Таблицы_Excel/Каталог_общий.xlsx` в «Каталог» книги: новые позиции — в пустые строки, изменённые — правятся (A–M, Q). Ключ: категория + производитель + модель + наименование. Запас O и формулы не меняются. Сначала показывает список и спрашивает. Позиции «только в книге» не трогает. Если файл не найден — спросит путь и запомнит. |
| Печать | Бирки | Создаёт лист «Бирки» по «Однолинейке». Изменили схему — нажмите снова. |
| | Наклейки | Лист «Наклейки»: клетка = 1 модуль DIN (18 мм). Проверьте пробной печатью. |
| Связи щитов | Связать с вышестоящим | Один щит — одна книга. В книге **нижестоящего** щита: выбрать файл вышестоящего и линию-фидер. Связи встают в обе книги: «Сеть_щита» раздел А (ΔU, Zп, Iкз, In от фидера) ↔ раздел Б вышестоящего (нагрузка щита). Вышестоящая сохраняется и остаётся открытой; свою книгу сохраните. Книги объекта — в одной папке. |
| | Обновить связи | Подтянуть свежие данные из связанных книг и показать, что изменилось. |
| | Дерево щитов | Все книги однолинеек в папке объекта: кто от кого питается, Руст, Iр, ΔU, Iкз, проверки — лист «Дерево_щитов». |
| Кабельный журнал | КЖ в DWG | Лист «Кабельный_журнал» → DWG по образцу `КЖ_шаблон.dwg`. DWG открывать не нужно. Первый раз спросит файл DWG и штамп. Ручные графы в DWG сохраняются. Подробно — `Кабельный_журнал.md`. |
| | КЖ: другой файл | Выбрать другой DWG (новый или готовый КЖ). |
| | Штамп КЖ | Выбрать файл штампа (внешняя ссылка рамки) и обновить КЖ. |
| Стадия П | ПЗ по объекту | В любой книге папки объекта. Создаёт рядом `ПЗ_<папка>.xlsx` (сводка, нагрузки щитов, расчёт нагрузок и режимы главного щита, категории по объекту, ΔU и КЗ на шинах, КЗ по линиям, дерево щитов, замечания) и `ПЗ_<папка>.docx` (расчётная часть ПЗ с таблицами и выводами). |
| Столбцы | Только ввод / Ввод + расчёт / Все столбцы | Какие столбцы видны на «Однолинейке» и «Исходных данных». Работает и на защищённом листе. |
| Справка | Как пользоваться | Короткая памятка. |

Типовые группы (`SX_Groups`) в надстройке остались, но кнопок нет: по коду таблица и так заполняет почти всё.
Вызов: Alt+F8 → впишите имя `SX_InsertGroup` или `SX_SaveAsGroup` → «Выполнить».

## Объект в подпапках

Книги объекта можно раскладывать по подпапкам одной папки: `Объект\ГРЩ.xlsx`, `Объект\Корпус 1\ЩР-1.xlsx`…
Связь хранит путь относительно книги. «Дерево щитов» и «ПЗ по объекту» сами поднимаются до главного щита и
обходят его папку с подпапками — запускать можно из любой книги. Переложили папку — «Обновить связи»
найдёт файл по имени в папке объекта и перенаправит связь.

## Пересобрать (после правки макросов)

```bash
py 3_Макросы_Excel/Надстройка/build_addin.py
```

Нужна галочка: Файл → Параметры → Центр управления безопасностью → Параметры центра → Параметры макросов →
«Доверять доступ к объектной модели проектов VBA». Перед сборкой закройте Excel с подключённой надстройкой.
