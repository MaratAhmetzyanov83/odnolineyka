# ГАЙД ПО ОДНОЛИНЕЙКЕ v3.12

Этот лист объясняет всю книгу: что вводить, где вводить и где смотреть результат. Текст написан по правилам ASD-STE100: одно действие в предложении, один термин — одно значение.

Читайте разделы по порядку. Разделы 4–14 — это порядок работы над щитом.

## 1. ТЕРМИНЫ

| Термин | Значение |
|---|---|
| Щит | Электрический щит. В одной книге может быть до 3 щитов («Питание_щита», столбцы C, D, E). |
| Линия | Отходящая цепь щита. Каждая линия имеет номер. |
| Номер линии | Текст вида «Код.Помещение.№». Пример: R.1.001A.1. Код — обозначение потребителя из «Справочной» P. |
| Место | Одна колонка схемы (шаг 20 мм). Одна строка «Разбивки» = та же строка «Однолинейки» = одно место. |
| Группа | Несколько мест на одном автомате. Автомат стоит в первой строке группы. |
| Ячейка ввода | Белая или жёлтая ячейка без защиты. Вводите данные только в ячейки ввода. |
| Расчётная ячейка | Ячейка с формулой. Значение считается само. |
| Синяя ячейка | Служебная ячейка. Не изменяйте её. |
| Вышестоящий щит | Щит, от которого питается этот щит (например, ГРЩ). |
| Нижестоящий щит | Щит, который питается от линии этого щита. |
| Фидер | Линия, которая питает нижестоящий щит. |

## 2. ПРАВИЛА КНИГИ

> **ОСТОРОЖНО:** Не вставляйте и не удаляйте строки и столбцы. Формулы используют постоянные адреса.

> **ОСТОРОЖНО:** Не используйте «Вырезать» (Ctrl+X). Используйте «Копировать» (Ctrl+C) и Delete.

> **ОСТОРОЖНО:** Не изменяйте синие и расчётные ячейки.

> **ОСТОРОЖНО:** Не переименовывайте файлы и листы после подключения связей. Связи щитов перестанут работать.

> **ВНИМАНИЕ:** Храните все файлы объекта в одной папке. Связи между файлами относительные.

> **ВНИМАНИЕ:** Перед массовой правкой сохраните копию книги. После макросов Ctrl+Z не работает.

Листы защищены паролем sx. Не снимайте защиту без необходимости.

## 4. ПОРЯДОК РАБОТЫ (КРАТКО)

6. Распределите фазы в «Нагрузке щитов» (раздел 10).  _(Нагрузка_щитов!E3)_
7. Заполните питание щита (раздел 11).  _(Питание_щита!B4)_
8. Задайте категории надёжности и пожарные линии (раздел 12).  _(Питание_щита!B62)_
9. В вышестоящем щите подключите нижестоящие щиты (раздел 13).  _(Нижестоящие_щиты!A1)_
10. Выполните проверку (раздел 15).
11. Возьмите результаты (раздел 16), нарисуйте схему (раздел 17), выпустите спецификацию (раздел 18).

6.1. Найдите код в столбце P (строки 4–51).  _(Справочная!P4)_
6.2. Если кода нет, заполните пустую строку: P — код, Q — потребитель, U — марка кабеля, V — жилы, W — напряжение, X — фазы, Y — сечение, Z — категория ПЗ.  _(Справочная!P4)_
6.3. В той же строке выберите AV — УГО, AW — 30 мА, AX — минимальный автомат, AY — клемм 3L на линию.  _(Справочная!AU4)_
6.4. Для пожарного кода проверьте BD («да» / «нет»). Формулу можно заменить значением.  _(Справочная!BD4)_
6.5. Задайте настройки однолинейки: BF4 — мест на лист A3, BF5 — минимальный автомат перед БП.  _(Справочная!BE3)_
6.6. Задайте настройки сети: BQ29 — Uн, кВ; BQ30 — общий К прокладки.  _(Справочная!BP28)_

7.6. N — выберите марку кабеля. O — введите число жил.  _(Исходные данные!N3)_

> **ПРИМЕЧАНИЕ:** Красная ячейка в строке показывает нарушение: потери напряжения, сечение, отключение КЗ. Измените кабель, длину или автомат.

## 9. ОДНОЛИНЕЙКА: АВТОМАТЫ, КЛЕММЫ, МОДУЛИ

Вводите данные только в белые столбцы: D, E, F, I–K, L, N, P, Y. Остальное считается само.

| Что нужно | Что ввести |
|---|---|
| Линия со своим автоматом | E = «авто». P = номер клеммы (XT5). |
| Несколько линий на одном автомате | Первая строка: E = «авто». Следующие строки: E пусто, P = XT6, XT7… Места группы ставьте подряд. |
| Автомат с текстом | E = текст, например «1P C16A». |
| Вторая шина (ИБП, секция) | D = имя шины (например, «ИБП») в строке с автоматом. |
| Линия на модуле (реле, диммер) | Первая строка модуля: L = модель. Последняя строка модуля: L = «-». |
| Канал модуля | N пусто — следующий канал. N = число — канал вручную. |
| Параллельная линия на тот же канал | N = «=». Строка стоит сразу за своей линией. |
| Резерв канала | N = «р». |
| Ещё одна клемма в тот же кабель | N = «+». |
| Линия без клеммы и канала | N = «б/к». |
| Аппарат после автомата | I, J, K = БП, T, МК, КМ (по порядку). |
| Строка только в таблице, без схемы | Y = «вручную». D, E, F, I–L, N, P пусто. |
| 30 мА | F = «да» или «нет». Пусто = по коду. |
Столбец AE «Статус»: красный — ошибка, жёлтый — проверьте. Сводка ошибок — ячейка AE1.

> **ВНИМАНИЕ:** Строки ниже автомата без E входят в его группу. Строка с Y = «вручную» прерывает группу.

> **ПРИМЕЧАНИЕ:** Подробная таблица случаев: 4_Инструкции/Как_заполнять_строки.md. Типовые группы: макрос SX_Groups.

## 12. КАТЕГОРИИ НАДЁЖНОСТИ, РЕЖИМЫ, ИБП

Вы вводите три вещи: схему щита, требуемую категорию линии, признак «пожарная». Остальное считается само.

12.1. «Питание_щита» C65 — число вводов: 1, 2 или 3.  _(Питание_щита!C65)_
12.2. C66 — АВР: «да» или «нет».  _(Питание_щита!C66)_
12.3. C67 — от какого ввода питается ИБП (ЩГП).  _(Питание_щита!C67)_
12.4. C70 — категория питающей линии. В связанных щитах её ставит связь с ГРЩ. Иначе введите вручную или оставьте пусто.  _(Питание_щита!C70)_
12.5. Если шина не «основная», задайте её тип в таблице B73:D82: Ввод 1/2/3, ИБП, ДГУ, Одиночная.  _(Питание_щита!B73)_
12.6. «Исходные данные» BN — требуемая категория линии: I особая, I, II, III. Пусто = III.  _(Исходные данные!BN3)_
12.7. BO — «да» для пожарной линии. Пусто = по коду («Справочная» BD).  _(Исходные данные!BO3)_
12.8. Посмотрите BV. «НЕ ОБЕСПЕЧЕНА» значит: требуемая категория выше, чем даёт схема щита.  _(Исходные данные!BV3)_

| Схема | Какую категорию даёт шина «Ввод» |
|---|---|
| 1 ввод, питающая линия пусто или III | III |
| 1 ввод, питающая линия I особая, I или II | II (один кабель не даёт I, ПУЭ 1.2.19) |
| 2–3 ввода без АВР | II |
| 2–3 ввода с АВР | I |
| Шина ИБП или ДГУ | I особая |
| Шина «Одиночная» | III |
> **ВНИМАНИЕ:** Для линии I категории щит должен иметь 2 ввода и АВР. Для I особой — шину ИБП или ДГУ.

12.9. Лист «Режимы»: выберите щит в C3. Смотрите нормальный, аварийный, пожарный режимы и таблицу по категориям.  _(Режимы!C3)_
12.10. Лист «ИБП»: заполните жёлтые ячейки (загрузка, cos φ, автономия, АКБ). Смотрите подбор ИБП и вход ИБП.  _(ИБП!A1)_
> **ПРИМЕЧАНИЕ:** Пожарные нагрузки не входят в расчётный максимум (СП 31-110-2003 п. 6.9). Они показаны отдельным режимом «Пожар».

> **ВНИМАНИЕ:** Ввод, который вы нарисовали вручную, пометьте в «Однолинейке» Y = «вручную». Иначе программа нарисует поверх.

## 18. СПЕЦИФИКАЦИЯ

18.1. Проверьте «Каталог»: N — по однолинейке, O — запас вручную.  _(Каталог!A1)_
18.2. Нажмите кнопку «Обновить спецификацию» (макрос SX_Spec).
18.3. Без макроса: скопируйте «Спецификация_авто» B4:J160. Вставьте в «Спецификация» B4 как значения.
18.4. После отправки снабжению нажмите «Принять изменения».
> **ОСТОРОЖНО:** «Обновить спецификацию» стирает «Спецификация» B4:J160. Ручные правки делайте в «Каталоге».

## 19. НЕИСПРАВНОСТИ

| Признак | Действие |
|---|---|
| Ячейка не изменяется | Это расчётная или синяя ячейка. Введите данные в ячейку ввода. |
| #Н/Д в наименовании | Код линии не найден. Проверьте номер линии и код в «Справочной» P. |
| «ПЕРЕГРУЗ» в AE | Ток линии больше номинала автомата. Увеличьте автомат или проверьте мощность. |
| «КАБЕЛЬ НЕ ЗАЩИЩЁН» в AE | Автомат больше допустимого тока кабеля. Увеличьте сечение или уменьшите автомат. |
| «НЕ ОБЕСПЕЧЕНА» в BV | Измените схему щита (вводы, АВР, шина ИБП) или требуемую категорию. |
| Старые значения из другого щита | Данные → Изменить связи → Обновить значения. Проверьте, что файлы в одной папке. |
| Excel спрашивает о связях | Нажмите «Обновить». |
| Линии ложатся друг на друга в AutoCAD | Проверьте: дубли мест, клемма без автомата, разрыв группы, «=» не рядом. |
