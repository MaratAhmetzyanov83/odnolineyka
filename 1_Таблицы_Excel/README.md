# Однолинейки — шаблон, пример и объект ЖД v3.12

| Файл | Что это |
|---|---|
| `Однолинейка_шаблон.xlsx` | Пустой шаблон щита v3.12 (категории, режимы, ИБП) — начинать новый щит отсюда |
| `Однолинейка_пример_ЖК-Остров.xlsx` | Заполненный пример |
| `Видеогайд_Однолинейка_v3.11.mp4` | Видеогайд по работе с таблицей (3 мин, субтитры) |
| `Объект ЖД/` | ГРЩ‑ЖД + 16 щитов v3.12, связанных с ГРЩ внешними ссылками; в ГРЩ собираются категории надёжности, пожарные и ИБП нижестоящих щитов (листы «Режимы», «Категории_по_щитам») |

**Правила:** не добавлять строки и столбцы, не трогать синие ячейки, не вырезать (Ctrl+X).

**Связи ГРЩ ↔ щиты** работают, только если все файлы объекта лежат в одной папке (ссылки относительные). Скачивайте папку `Объект ЖД` целиком. Если Excel спросит про обновление связей — «Обновить»; при перемещении файлов по отдельности связи придётся переуказать («Данные → Изменить связи»).

Что считается и по каким нормам, история версий и найденные замечания — в `_Разработка/2026-09-29_demand-factor-ks/README.md`.
