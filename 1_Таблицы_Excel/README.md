# Однолинейки — шаблон и пример v3.12

| Файл | Что это |
|---|---|
| `Однолинейка_шаблон.xlsx` | Пустой шаблон щита v3.12 (категории, режимы, ИБП) — начинать новый щит отсюда |
| `Однолинейка_пример_ЖК-Остров.xlsx` | Заполненный пример |

**Правила:** не добавлять строки и столбцы, не трогать синие ячейки, не вырезать (Ctrl+X).

**Связи ГРЩ ↔ щиты** работают, только если все файлы объекта лежат в одной папке (ссылки относительные). Если Excel спросит про обновление связей — «Обновить»; при перемещении файлов по отдельности связи придётся переуказать («Данные → Изменить связи»).
