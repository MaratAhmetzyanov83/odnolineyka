# Однолинейка — правила для агента (Claude, Codex и др.)

1. Сначала прочитай `СОСТОЯНИЕ.md`: финальный контур, журнал, очередь «Дальше». Старый журнал — `СОСТОЯНИЕ_архив.md`: только поиск по слову.
2. Перед работой: `git pull --rebase --autostash` (или пользователь жмёт `Получить.cmd`).
3. После работы: допиши «Журнал» и «Дальше» в `СОСТОЯНИЕ.md`, затем `Отправить.cmd` (или commit + push).
4. Не коммить файлы > 95 МБ — GitHub их не принимает. Базы блоков — см. `СОСТОЯНИЕ.md`.
5. Отвечай пользователю коротко, по-русски, на 80 % по ASD-STE100 (просьба пользователя: всегда): короткие предложения,
   одно действие — одно предложение, простые слова, действительный залог.
6. Таблицу v3.12 не перестраивай. Своя копия Excel / AutoCAD, закрывай только свои процессы.
7. Экономия: механическую работу отдавай помощникам из `.claude/agents/` — прогон проверок → `tester`,
   pull / commit / push → `git-sync`, поиск по коду без правок → `finder`. Сам делай проектирование,
   правки логики и разбор ошибок. Результат помощника проверяй по сути (итог, diff), прежде чем сообщать.
